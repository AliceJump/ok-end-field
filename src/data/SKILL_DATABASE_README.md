# 角色技能强化/反应依赖数据库

基于明日方舟：终末地Wiki数据整理，用于自动化技能释放决策。

## 目标

本数据库的目标不是制作普通技能资料表，而是分析：

- 哪些技能组合会产生特殊反应
- 哪些反应会激活技能强化态
- 哪些强化态会影响自动释放逻辑
- 哪些技能在当前条件下不应该提前释放普通状态

## 核心数据模型

```
技能
↓
触发条件 / 反应
↓
强化状态 / 增幅状态
↓
影响技能
```

## 已收集角色

### 1. 莱万汀（灼热·突击·单手剑）
- **普通攻击**：燃烬 - 5段攻击，造成灼热伤害
- **战技**：焚灭 - 召唤熔核碎片，获得熔火层，4层时触发追加攻击
- **连携技**：沸腾 - 当敌人进入燃烧或腐蚀状态时触发
- **终结技**：黄昏 - 强化普通攻击，战技和连携技期间持续时间不减少

**强化态**：
- 熔火层数系统（0-4层）
- 达到4层后获得无视抗性效果
- 终结技期间战技效果增强

**反应/组合效果**：
- 燃烧/腐蚀状态 → 触发连携技沸腾
- 熔火层数 → 触发战技追加攻击
- 终结技期间 → 战技效果增强

### 2. 伊冯（寒冷·突击·手铳）
- **普通攻击**：雀跃扳机 - 5段攻击，造成寒冷伤害
- **战技**：冰冰弹·β型 - 发射制冷弹，命中寒冷/自然附着敌人时消耗所有法术附着，强制施加冻结
- **连携技**：速冻仔·υ37 - 当主控干员对处于冻结状态的敌人造成重击时触发
- **终结技**：冷冻射手 - 强化普通攻击，增加暴击率

**强化态**：
- 冻结状态触发机制
- 战技可以消耗法术附着层数造成额外伤害
- 连携技需要冻结状态触发

**反应/组合效果**：
- 寒冷/自然附着 → 战技消耗附着 → 强制冻结
- 冻结状态 → 触发连携技速冻仔·υ37
- 终结技期间 → 普通攻击强化

### 3. 洁尔佩塔（自然·辅助·施术单元）
- **普通攻击**：秘杖·束能技艺 - 4段攻击，造成自然伤害
- **战技**：秘杖·引力模式 - 产生重力奇点，吸引敌人并造成伤害
- **连携技**：秘杖·矩阵位移 - 当有敌人被施加法术异常时触发
- **终结技**：秘杖·重力场 - 创造重力紊乱区域，施加缓速和法术脆弱

**强化态**：
- 技能主要基于法术异常状态
- 连携技需要法术异常触发
- 终结技可以增强法术脆弱效果

**反应/组合效果**：
- 法术异常 → 触发连携技矩阵位移
- 破防状态 → 增强终结技法术脆弱效果
- 击飞状态 → 在终结技区域内保持击飞

### 4. 余烬（灼热·重装·双手剑）
- **普通攻击**：陷阵剑术 - 4段攻击，造成物理伤害
- **战技**：进军 - 向前跃起重砸，造成灼热伤害和倒地
- **连携技**：前线援护 - 主控干员受到攻击后触发，造成伤害并治疗
- **终结技**：重燃誓约 - 猛击地面，造成伤害并给全队护盾

**强化态**：
- 技能主要基于受击触发
- 连携技需要主控干员受到攻击触发
- 天赋可以叠加攻击力

**反应/组合效果**：
- 主控干员受击 → 触发连携技前线援护
- 受击 → 叠加攻击力层数
- 终结技 → 全队护盾

### 5. 骏卫（物理·先锋·单手剑）
- **普通攻击**：全面攻势 - 5段攻击，造成物理伤害
- **战技**：粉碎阵线 - 两段斩击，造成物理伤害并施加碎甲，基于消耗的破防层数恢复技力
- **连携技**：盈月邀击 - 当有敌人被猛击或碎甲消耗破防层数后触发
- **终结技**：盾卫旗队，上前 - 召唤四名盾卫，消耗铁誓触发后续效果

**强化态**：
- 破防层数系统
- 战技可以消耗破防层数恢复技力
- 连携技需要破防层数消耗触发

**反应/组合效果**：
- 猛击/碎甲消耗破防层数 → 触发连携技盈月邀击
- 破防层数消耗 → 战技恢复技力
- 终结技铁誓消耗 → 召唤盾卫袭扰
