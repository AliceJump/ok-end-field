> 截止本地安装资源快照：2026-10-03。适用于 PR #436 的第一阶段数据工作，不表示完整战斗机制模拟已经完成。

伤害加成、增幅、脆弱、天赋与潜能的执行覆盖见 [伤害增益接入梳理](damage-modifier-integration-audit.md)。

## 基准口径

| 项目 | 默认值 | 依据与边界 |
| --- | --- | --- |
| 普通六星，含常驻与限定 | P0 | 用户口径；不按热门配队推断账号高潜 |
| 四、五星 | P5 | 用户口径；所有潜能逐阶保留，基准选取到第五潜 |
| 管理员 | P3 | 用户明确指定的模拟基准；当前客户端有效定义到第三潜，第四、第五条为未定义占位。此选择不代表已核实第三份免费材料的获取入口 |
| 战斗天赋 | 各槽最高阶、全部解锁 | 同槽低阶不与高阶叠加；提弗洛斯有三阶天赋，不能统一假定最高二阶 |
| 属性节点 | 全部解锁 | 原生属性节点独立保存；余烬的对比明确计入全部节点 |
| 余烬对比 | 80级、技能9级、P0、终点之声 | 本地推荐表第一组中的首把五星武器；武器90级、武器技能9级，沿用现有推荐装备及精锻口径 |

这是模拟基准，不能替代玩家实际账号养成。`CombatBaseline.potential` 可以显式覆盖；所有潜能定义仍在数据中，P0 不会误删后续潜能。其他角色尚未建立统一的等级/武器对比档案，不沿用余烬的专用档案。

解码布局来自本地 native read plans，与安装客户端 GameAssembly/metadata 的 SHA256 一致；VFS 每段解密后验证索引 MD5。补充资源每条均重新编码，并与解密原字节完全一致，保留原始 zip、记录哈希、VFS bucket/chunk/span 和验证报告。回编码验证证明解码无损，不单独证明每个动作的游戏语义已解释完整。

`tables.json.gz` 保存相关原生表和文本；`supplement.json.gz` 保存完整新增条件树；`resource_actions.json.gz` 保存动作及指向完整树的路径、祖先路径。嵌套 IfElse、Switch、命中/受击监听、时间线等均不扁平化成必定回复。

文本优先使用当前 I18n 表，支持有符号十进制 ID 和旧无符号十六进制 ID。BB 参数只有唯一来源时才填入；无法解析的属性/条件表达式保留模板占位，不猜测成零。原生 modifier 的运算码与生效条件保留，交由后续解释器处理。

数据快照由仓库外的本地研究流程生成。仓库只保留可复核的结果、哈希、导入器和验证逻辑，不提交客户端提取/解密脚本、客户端程序、完整中文表或解密密钥。

## 管理员例外的证据边界

`chr_0002_endminm` / `chr_0003_endminf` 的成长表仍含旧天赋；当前模型改读共享 `chr_9000_endmin`。

当前最高阶天赋定义为消费源石结晶后自身攻击力 +30%、持续15秒，以及源石结晶目标物理承伤 +20%。有效潜能前三条分别涉及战技消费结晶返还50 SP、攻击增益对队友半效，以及终结技消费结晶每个获得15终结能量且不受终结能量获取效率影响；不是额外独立的无条件 cast 回复。

扫描当前 VFS 的 531 条 MissionRuntimeAsset meta，相关引用及哈希保存在 `endmin_reward_scan.json`：

- `e6m5` 指向 `reward_mission_e6m5_new`，含一份潜能材料。
- `e11m7` 指向 `reward_mission_e11m7`，含一份潜能材料。
- `e2m8` 当前指向 `reward_mission_e2m8_new`，这条当前奖励不含材料；旧 `reward_mission_e2m8` 含材料，不能把旧条目额外计数。
- 旧版/新版奖励、活动跳章替代奖励以及通用物品奖励不能直接累加成可获得潜能数。

管理员的 `potential` 按用户指定设为 3、`potential_basis` 标为 `user_endministrator_p3`；有效前三条潜能参与基准选择。第三份免费材料的当前有效入口仍需进一步核查活动/系统奖励或账号实测；不将用户的模拟选择当作奖励可达性证据。其他未知账号档案仍可保留 null，求值前必须显式选择潜能。[当前管理员展示页](https://warfarin.wiki/cn/operators/endministrator) 可交叉核对潜能定义，不能替代当前奖励可达性证明。

## 本次 canonical 修正与资源归一

新增伤害修正绑定：canonical技能中的31个增幅/脆弱/攻击/暴击效果均引用明确的等级表或原生参数，13条天赋/潜能定义单独保存于 `damage_modifier_rules.json`，随成长快照导入并校验哈希。这里只统计已有绑定，不表示所有被动已执行；诀形态分支与提弗洛斯箭阵仍有未决参数。固定配装及已选潜能的常驻属性先计算为32角色面板，普通战技估计已读取该基准并执行明确的基础增益生产者。实际逐段时间线、条件事件与场地生命周期仍待接入，详见伤害增益审计。

新增资源字段 `trigger`、`count_basis`、`affected_by_energy_gain`、`max_amount`，以及分支 `evaluation_point`。数量读取明确区分消费量、动作前快照、命中目标数、击杀数。`None` 仍表示未知，不代表无条件结算。

- 伊冯：终结技提供7秒辅助姿态，普通攻击暴击累积最多10层，每层提高3%暴击率；达到10层额外60%暴伤。避免 cast 直接获得满层暴击。冻结后的能量按实际消费附着数结算，最多4层。
- 提弗洛斯：战技/连携/终结技重置5次浮空普攻额度，逐次消费；第五次受控普攻的强化条件与猎矢分支分开，重置使用 replace 语义。
- 莱万汀：4熔火判定使用动作前快照；战技命中才产生熔火，避免 cast 先加层使自己满足条件。770%追加攻击与强制燃烧归属强化分支；终结技姿态与第三段普攻附着分开。
- 卡契尔、昼雪：护盾开始时返还30 SP，命中反击才施加破防/寒冷附着。
- 阿列什：终结技起始25 SP、每击杀15 SP、总返还上限100；不能忽略总上限。
- 诀：囹圄相关30 SP 归战技命中分支，连携10终结能量独立保存。
- 佩尔希：战技起始20 SP、首次格挡另20 SP；天赋首次格挡10终结能量独立，不能把技能与天赋合成重复无条件回复。
- 梨诺、庄方宜等补充连携能量与实际消费数；骏卫终结技普通干扰10 SP、末次决胜40 SP 保留互斥分支。
- 余烬：终结技护盾 recipient 为全队；静态战技失衡值10，受击后的额外失衡保持条件项。

`semantic_rules.json` 保存依据技能、天赋与潜能描述提取，并与原生数值核对的资源规则，涵盖管理员、阿列什、艾维文娜、别礼、梨诺、昼雪、狼卫、弧光、卡契尔、安塔尔、秋栗、佩尔希等。潜能增加某个天赋回复量时明确是 delta，不注册成第二个独立 producer。智识相关比例、概率、冷却和条件保留动态语义，不提前执行。

## 描述驱动的资源核对（2026-10-03 补充）

规则提取先读技能、天赋、潜能描述，再从 rank_stats 或同版本 BB/参数补数值。描述明确的回复量、触发条件、每层计算、上限直接结构化；条件树用来补齐未写清的结算次数、先后顺序、技能变体和互斥关系。无需把所有规则都当成等待逆向研究的未知项。

最高阶64项战斗天赋与全部160条潜能定义中，含技力/终结能量语句的62条定义已逐项记录在 `description_resource_review.json`：27条回复定义、32条消耗/回复倍率修改、3条资源监听定义。62条是描述定义数，与481处原始动作的计数口径不同；回复定义中阿列什天赋含基础与追加两条规则。

新增10条明确的潜能回复规则：诀智分支+10、莱万汀追加攻击+20、别礼原战技回复+5、梨诺入战后的首次战技+25、骏卫战技命中至少两目标+15、洛茜狼之珀命中+10、汤汤每消费涡流+5、伊冯连携回复+15及战技爆炸只命中单目标+10、庄方宜实际消费导电+10。零潜六星保留定义，默认不启用这些高潜规则。

29条终结技降耗潜能根据描述与原生 `skillParamModifier` 生成 `PassiveResourceModifier(scope=cost, operation=multiply)`；同一潜能的多个技能变体归于同一修改规则。`costvalue`/`costValue` 模板别名从唯一原生消耗乘数填入，现在能够显示正确的10%/15%等降耗数字。卡缪连携/追猎×1.15、骏卫连携×1.2通过描述和BB核对后作为回复倍率修改保存。秋栗智识相关回复增幅也保存为参数化倍率公式，rate/sub_ratio/max_ratio绑定原生BB，达到上限后不再增长。修改规则不独立产生资源回复。

秋栗“恢复技力后获得攻击增益”、骏卫“每恢复80技力获得士气”及降低士气门槛的潜能属于资源监听/状态规则。原始producer完整保留，审计明确分类，不把它们登记为回复事件。完整监听及状态叠加仍由执行层实现。

这份描述核对的零未归类只覆盖上述62条定义，不能扩大为所有隐藏原生动作已解释完成。普通攻击描述中的共用处决回复、通用能量获取与未公开数值，还需结合全局战斗参数继续核对；未明确数值不能编造成固定回复。

## 余烬对比

生成结果位于 `assets/data/ember_progression_baseline.json`，不覆盖旧的全角色90级静态基准。

在已记录的推荐装备、五星终点之声、80级、技能9级档案下，静态面板 ATK 3165.5。战技倍率312%、基础失衡10；连携按自身物理元素计算；普通攻击倍率431%，处决/下落攻击不混入普通连段。天赋已列入档案，受击触发攻击增益在未受击的标准假人状态下不提前施加。

这些结果只用于检查直接伤害口径，输出不包含假设两套普攻或满连击的循环期望。要回答“进军是否值得100 SP”，仍必须计入破防链边际收益、后续动作解锁、资源返还、动画时间、机制重复/溢出及机会成本，不能用这份静态数据直接下结论。

## 重跑入口

仓库只保留已经生成的快照、快照导入器与基准计算器。客户端 VFS/原生资源提取属于仓库外的本地研究步骤；准备好与当前快照兼容的研究导出后，再显式传入目录运行导入器，不在文档中写死任何个人机器路径。

```powershell
$research = $env:ENDFIELD_RESEARCH_DIR
if (-not $research) { throw 'Set ENDFIELD_RESEARCH_DIR to a prepared local research export.' }
uv run --locked python -X utf8 scripts/skill-data/import_native_progression.py --research-dir $research --texts "$research/mechanics-tables/I18nTextTable_CN.json"
uv run --locked python -X utf8 scripts/skill-data/compute_progression_baseline.py
uv run --locked python -X utf8 -m unittest tests.TestCharacterProgression tests.TestCharacterSkillEffects tests.TestEffectSemantics tests.TestSkillDataSnapshots tests.TestCharacterMechanics tests.TestCharacterCapabilities tests.TestCombatModel -v
```

任务奖励扫描是单独的本地核查结果；导入器在对应结果存在时复制并记录哈希，否则不生成任务获取证据。仓库不提供客户端提取或解密入口。

## 远程整理后的复核

以远程整理版本29255af6为起点，继续保持客户端提取/解密入口与个人机器路径的删除；保留数据结果、哈希、导入器及无损验证。

- 管理员的有效定义上限P3不代表免费获取上限；基准采用用户明确指定的P3，并单独标记选择依据，未知账号档案仍拒绝隐式启用潜能。
- 余烬对比继承的“两套普攻+技能”和满连击循环估算未验证动作、时间和资源供给；从独立产物移除，只保留面板与逐技能直接伤害。
- 赛希晶体的动态消费条件不能证明晶体生产技能没有价值；allowlist保留存在明确消费关系的生产技能。只记录潜在依赖，不把消费条件当成已满足，也不恢复角色名特判。
- 三项旧schema断言仍期待空all或将动态兜底视为静态条件，已按当前未知值口径更新；同时阻止空条件组被当成“总满足”。测试对照改用真正的PR父分支。

## 验证与后续边界

针对数据、loader、资源约束、最高阶选择、管理员例外、降耗/回复倍率、描述资源分类、快照路径、无损解码、战斗模型与 allowlist 的109项测试通过。全仓标准入口运行879项，剩3个失败、4个错误；本次使用真正的 PR base aeee74a4 导出并在同环境运行862项，4个失败、4个错误。剩余7项全部在真实父分支中复现，涉及排轴状态、反馈测试 harness 和技能时序 fixture。此前866项对照版本是包含本 PR 早期改动的 bff2b213，不能据此宣称失败在父分支中原有；该结论已撤回。
