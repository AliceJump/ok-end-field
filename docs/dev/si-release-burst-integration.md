等级12参数为 enhance_final=0.36000001430511475、enhance_duration=12，canonical 描述为36%全队寒冷和灼热增幅。buff 的事件5是 DuringBuffEnable，两个启用的 EnhancedAction 分别为寒冷/灼热，并作为子对象随该buff清理。父buff固定时长、Stack=2/max=1，同源刷新；创建块不自动结束、不是来源技能的child，因此不因祀下一动作而移除。模型采用释放后62/30秒起、随后12秒的名义窗口，重复确认去重，到期移除；这不声称已解释整个实体程序、运行期所有中断或当前客户端全部旧记录。

增幅与同桶增幅相加，按每个动作的实际元素过滤，包括符合元素的祀本人。它不会给电磁/自然/物理动作增加伤害，也不会重复添加固定武器/套装词条。仅有祀可用或没有合法受益动作时，不因为这份支持报价强行提前终结；后续战技仍计公共SP。
