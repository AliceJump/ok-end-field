释放确定后才把姿态写入实际状态；搜索使用独立副本，终结失败不生产姿态。头像未知补全只继承角色未改变的槽位，来源禁用清理姿态。收益进入真实 TimedCombatLogic.step 的候选顺序、后续伤害和共享SP预算：公共SP为0时也可评价终结→首次免费战技；免费资格在模拟执行该战技后消费，之后战技恢复100SP。终结个人能量仍由已有HUD就绪约束。

强化普攻仅在既有当前主控箭头明确指向庄方宜时作为输出尾项，不自动切换主控或新增普攻识别。报价用三段动作的实际allow-next边（含第三段回第一段）和原调度器宽限，共约3.783秒，取代普通链时间。该时间是原生允许续招提示，不是实测DPS或命中证明。完整强化动作不能跨过名义姿态到期仍计满收益。

战技继续使用与原基础报价一致的“单次雷击单位”口径。本批不虚构场上3/9柄剑、不推定每个目标命中、不估计导电等级；因此不把整个青霆剑齐射当作已经模拟。原描述首次免费战技有目标时产生3柄剑，以及末击6倍、导电追加、最后命中附着、强化连携倍率/4倍冷却均保留原数据，但未成为本层额外预测收益。匿名连携继续master处理。

原生普攻内的ExtendBuffAction和终结duration_extra=1也保留证据，完整延迟退出/外部中断链没有实际观测输入，暂不延长25秒名义窗口。P5无视电磁抗性不适用于本批P0。天地造化的条件mark、层数和生命周期没有被这份姿态合同替代。

数据来自干净研究提交cc9b471b50cdd6bc8b3a148b4eca93deef4efa02的哈希校验解包：ultimate_skill、ult_base、ult_skill_free、normal_skill_ult、attack1/2/3_ult及选中等级blackboard。导出审核边界为 scripts/skill-data/reviewed_release_stance.py；snapshot.json保存原生记录SHA256、等级参数、78帧起点、三段倍率和续招时间证据。运行时不加载原生编译器。改潜能或技能等级需重新审核。
