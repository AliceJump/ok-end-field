# 导航网格实现（3D 体素，机器可读）

返回：[文档索引](../zh-CN/README.md) / [README](../../README.md)

## 概述

`src/nav/` 提供一套**机器可读**的导航系统，核心是 **3D 体素网格**
（1×1×1m 一格），不做任何可视化。

可达性模型：

- **默认所有格子不可达**；
- 已知位置（走过轨迹 / 物品点位 / 传送点 / 滑索端点）标为 free 种子，
  **只有当前坐标处的单元格 free**（不做周围膨胀）；
- **blocked**（标记墙 / 卡住）覆盖 free，永不可达；
- 寻路 **6 连通**：free 格代价 1，未知格（包围盒内、非 free 非 blocked）
  代价 `risk_cost`（默认 5×）表示「冒险尝试」；
- **垂直方向只进 free**（爬台阶走已走过的格），未知格仅水平方向可冒险；
- 传送零成本（多源 A*）；滑索为双向特殊边。

## 目录与文件

| 文件 | 职责 |
|------|------|
| `src/nav/grid.py` | `GridMap` 稀疏体素网格（free/blocked、序列化）、`build_grid` |
| `src/nav/grid_finder.py` | `GridFinder` 6 连通 A*、`GridPlan` |
| `src/nav/nav_runner.py` | `NavRunner` 执行状态机：朝向/行走/滑索/传送、战斗暂停、卡住重规划 |
| `src/nav/storage.py` | `configs/nav/` 读取、扫描 mapId |
| `src/tasks/test/NavToPointTask.py` | 「导航到坐标点」任务（导航执行 + 冒险） |
| `scripts/build_nav_grid.py` | 建网格 CLI |

数据位置：

- 建图输入：`configs/nav/`（`trails_<mapId>.jsonl`、`zips_*.json`、
  `teleports_*.json`、`blocked_*.json`；由外部采集/学习工具产出）
- 派生产物：`assets/nav/<mapId>.grid.json`（3D 轨迹网格；
  以及可选的导航网格编辑器二维产物 `<mapId>_<zoom>_2d.grid.json`）

## 数据模型

```json
{
  "origin": [x0, y0, z0],
  "cell_size": 1.0,
  "cells": [[ix, iy, iz], ...],      // free 种子格
  "blocked": [[ix, iy, iz], ...],    // 标记墙/卡住
  "teleports": [[ix, iy, iz], ...],  // 传送点（含标定「协议传送点」）
  "zips": [[[ax,ay,az],[bx,by,bz]], ...]  // 滑索双向
}
```

`GridMap` 加载后把 `cells` 剔除 blocked 得到实际 free 集合（不做膨胀）。

## 建网格

```bash
uv run python scripts/build_nav_grid.py --map map01
uv run python scripts/build_nav_grid.py --map all
```

输入 `configs/nav/` 的轨迹/滑索/传送点/受阻经验 + `summary.json` 的物品点位；
`--teleport-items`（默认「协议传送点,传送台」）里的点位按传送点入图。

## 寻路

```python
from src.nav import GridMap, GridFinder

grid = GridMap.load("assets/nav/map01.grid.json")
res = GridFinder(grid).find_path((x, y, z), (tx, ty, tz),
                                 snap_radius=4.0, allow_risk=True, allow_teleport=True)
# GridPlan: ok / waypoints(格中心) / segments(["walk"|"zip"]) / cost / risky / via_teleport
```

- 起点吸附最近 free 格（超 `snap_radius` 且 `allow_risk` 时冒险就近格）；
  **吸附做直线视线检查**：直线穿过 blocked 墙的候选会被跳过，只选"看得见"的
  最近 free 格（防止冒险段盲走撞墙）；`find_path(..., snap_exclude={...})` 可
  排除指定格（卡住重规划换方向用）；
- 终点：free 直达；blocked 失败；未知且风险范围内 → 冒险直达该格（尝试走到）；
- 多源 A*（起点 + 各传送点）保证传送零成本；启发式欧氏距离可采纳。

## 二维网格（导航网格编辑器产物）

`GridMap` 支持直接加载「导航网格编辑器」（nav-grid-editor）导出的**无高度 2D
网格**：`cells`/`blocked` 为 `[x, z]` 二元组（如
`base01_4_2d.grid.json`，origin 保留 3 元素作基准）。加载时自动识别为
`is_2d=True` 并归一化到基准层 `iy=0`：

- `cell_of` 忽略传入的 y（任意高度都落到基准层）；
- `nearest_free` 忽略高度容差，只按 xz 平面吸附；
- 寻路只走**水平 4 邻接**（跳过垂直方向，防止上下绕墙）；
- 序列化回写 `[x, z]` 格式，往返一致。

```python
grid = GridMap.load("assets/nav/base01_4_2d.grid.json")
assert grid.is_2d
res = GridFinder(grid).find_path((px, py, pz), (tx, ty, tz), snap_radius=8.0)
```

「导航到坐标点」任务加载顺序与「网格模式」配置：默认**自动**——先
`assets/nav/<mapId>.grid.json`（3D 轨迹网格），缺失时回退到
`<mapId>_*_2d.grid.json`（多个 zoom 取 free 格最多的那份，
`storage.pick_best_2d_grid`）；也可在任务配置里显式选 **3D(轨迹网格)** /
**2D(编辑器网格)**，只使用对应数据。想直接换用二维网格而 3D 文件仍在时，
可把二维文件复制/另存为 `<mapId>.grid.json`（加载器自动识别 2D 格式）。

## 执行（NavRunner）

```python
from src.nav import NavRunner, RunnerConfig

runner = NavRunner(grid, controls, RunnerConfig(
    arrive_radius=1.0, snap_radius=4.0, allow_risk=True, risk_cost=5.0,
    allow_teleport=False, stuck_window_s=3.0, stuck_min_dist=0.5))
runner.set_combat_check(task.in_combat)
runner.on_plan = task._on_plan_log       # 每次规划输出拐点（可选：便于排查）
runner.navigate_to((tx, ty, tz))
# 循环每 ~0.2s：
runner.step((x, y, z))
```

行为：

- **卡住重规划 + 连续卡住防护**：`stuck_window_s` 内位移不足 → 先脱困
  （侧移+前进，任务层 `recover_stuck_cb`），仍卡住则重规划；**同一格连续卡住
  第 2 次**重规划时吸附排除该格及其相邻格（强制换目标方向），**第 3 次直接
  失败**（"同一位置连续卡住 3 次"），避免反复撞同一面墙死循环；
- **战斗自动暂停**：`set_combat_check` 注入 `in_combat`，战斗中松键挂起，
  结束自动重吸附重规划；
- **冒险起始段**：`risky_start` 时先走向最近 free 格（吸附带视线检查，不穿墙）；
- **滑索/传送**：zip 边走 `ride_zip` 钩子，传送首跳走 `teleport` 钩子。

## 导航到坐标点（NavToPointTask）

一次性任务：配置目标 X/Y/Z（地图 id 留空跟随当前位置）→ 按「网格模式」加载网格
（自动/3D/2D，见上）→ 执行 NavRunner；**每次规划（含卡住重规划）输出拐点位置
日志**；到达/规划失败/超时后自动禁用。配置项含网格模式、吸附半径、允许冒险、
yaw_per_pixel、朝向偏移、卡住参数。

位置源一致性：**任务启动后的首次规划要求收到本会话的新位置**（不会用上一会话的
陈旧缓存坐标当起点）；等官方地图 WS 连接上报后几秒内自动开始，或填「起点坐标」
显式指定规划起点绕过等待。
