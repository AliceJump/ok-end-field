# 加成接入名单（2026-10-08）

本次只统计，不接master、编排或识别端。口径为现有逐角色/技能审计及已批准的模型合同；“首批候选”表示可准备接入确认动作与结算入口，不表示原生完整producer或实战验证已完成。机器明细见[buff-integration-inventory.json](buff-integration-inventory.json)，可用`scripts/skill-data/inventory_damage_bonus_bindings.py --out docs/dev/buff-integration-inventory.json`重生成。

| 合计 | 62 | 按角色、来源、触发/分支计数，不能当62个独立buff |

这62条由33条技能（含分支）、15条选中被动、10条武器/套装释放、2条武器目标条件及2条原生实例构成。14条释放绑定中的4条技能规则已在33条中，只计一次。相同武器跨角色、同一技能的不同分支分别登记；因此先接的是7条释放候选和有输入时的6条条件结算，其他条目不阻挡首批。

另外有8份原生证据候选，含陈千语/佩丽卡增强ATK、负山两分支、三份当前配装启用的下一技能套装及庄方宜标记增幅。庄方宜与62条中的天地造化同源，不能直接相加。三份碾骨散件配装未激活，明确排除。该名单统计已登记的伤害加成合同，不宣称所有游戏buff、免疫/治疗状态或所有装备条件已穷尽。

## 固定数据一起接入，不再次产生动态buff

32份固定角色面板及128份基础报价：角色成长、力量/敏捷/智识/意志、主副属性floor转攻击、固定武器/装备词条、套装常驻词条、已纳入的常驻天赋/潜能，以及固定的元素/技能类型过滤。重点保留陈千语扶摇的物理战技/终结+42%、佩丽卡P5终结暴击率+30%的技能类型过滤，不加到其他技能。

潜能：六星P0、管理员P3、其他星级P5；最高阶天赋。余烬80级/技能9/推荐五星武器，其余沿用固定profile，不在此次名单里改基线。动态四维百分比及黎风智识/意志转换刷新不属于固定面板已解决的内容。
