# 艾维文娜收枪报价修正

技能时间排轴不再将战技的三行倍率直接相加。固定配装不变，专精3/P5下的名义旋风为150%，约19646期望伤害；普通雷枪每次回收命中168%、强雷枪432%分别保留为条件分量。此前750%、约98231的固定报价隐含了各一次回收命中，不能作为任意战技的无条件报价。

## 真正影响的路径

- 战技候选使用旋风报价，J.E.T.、梨诺等已有增益仍按正确乘区作用于这个值。
- `price(value=旧整段报价)`不能绕过此合同重新加入未确认回收伤害，覆盖终结/增益规划之外的防溢出报价调用。
- 当前循环规划的`DamageQuote.battle/conservative`也采用同一报价，避免周期搜索继续按旧固定750%评价。
- 当前候选含此类受限战技时，无动态增益贡献的赢家也可执行修正后的比较；但若没有已知连携、旧循环中仍有合法可用的保留辅助战技，则沿用旧循环推进游标，避免零伤害辅助被永久绕过。辅助尚未可用时不阻断其他选招，正收益团队增益及已知连携编排继续按已有规则处理。

真实`TimedCombatLogic.step`回归使用用户这支庄方宜/佩丽卡/艾维文娜/梨诺队伍：100SP、无可用终结、庄方宜无白圈、普通/强枪未知时，选择佩丽卡战技，而非按旧98231报价抢放艾维文娜。艾维文娜白圈亮仍不能提供枪种/数量及回收路径命中事实。

## 验收边界

这是条件伤害误计与实际排序的修复，不是整套实战排轴已经完成。没有新增枪数、重击、命中、距离或目标识别；接受连携/终结不自动创建3支/1支有效枪，也不把下次回收当作已命中。真实铺枪计数、到期/提前消失和回收目标路径仍待有效输入；未启用这些条件伤害。因此已有枪但无法确认时可能低估收枪收益，不能将本次修正称为完整铺枪—收枪循环。

没有照抄相近视频中的弧光技能到用户队伍。主控切换策略、梨诺战技开关链和新连携增益producer不随本批引入；旧UI伤害基准及关闭技能时间排轴时的原自动战斗保持既有行为。未游戏现场复测。

## 本批验证

6项新增回归覆盖旋风/普通枪/强枪分拆、旧整段值不可覆盖、零增益赢家仍执行、接受连携/终结不冒充枪数、实际四人队按键和防溢出/周期报价一致。175项相关、全仓1465项（90.825秒）通过；122文件/16职责组登记、5份Python AST、Ruff I/F、diff-check通过。逐项对照确认33面板/配装/profile、15规则、其他131份报价及庄方宜姿态均未改。

评审续批新增赛希零伤害战技公平性回归：即使旧游标尚在其他输出角色、预测普攻较高，也不因新收枪比较持续绕过仍可用的保留辅助；真实step按旧计划释放并在SP确认后推进游标。辅助处于状态锁不可用时，其他角色仍按修正报价竞争。未采纳“只有修正角色是首动作才接管”的建议实现，因为那会再次把较高收益的佩丽卡退回旧排序；修复聚焦于未建模辅助价值的既有保留合同。
