# 终结可用与不可用的分情境估价

2026-10-19。真实排轴不再只用当前普通战技的单次报价衡量是否开启庄方宜姿态。没有相关终结、也没有已跟踪长姿态时，沿用12秒局部模式；有就绪终结或当前姿态时，按已知释放增益/姿态窗口展开，并让不开终结的路线使用同样长度比较。

## 终结开启的依赖路线

庄方宜就绪终结的比较窗口为`starts_after 2.6 + duration 25 = 27.6秒`。窗口内搜索可安排终结、队友增益、首次免费战技和多轮已有主控普攻。终结花费已有个人能量就绪机会及动画时间，不消耗公共SP；费用由预测姿态分支重算，战技不因还没开终结就被提前当作当前0SP按钮。

未来免费候选保存`requires_free_battle`。若它只是因就绪终结才能纳入，必须先在同一路线里获得有效且未消费的免费资格；普通态或删除终结的反事实里不可执行。实际仍先按终结，恢复后重新读取当前按钮/白圈；失败不生产姿态、请求或天赋。首免接受前不提前登记生成历史。

原执行路径会在终结恢复处强插机制战技。由本层选出的姿态终结现跳过这次强插，保留免费资格，回到下一帧规划，避免越过应先释放的梨诺增益。未纳入本层的其他多段机制继续原处理。真实双step回归核准终结恢复超过3.2秒、白圈已亮时也不会擅自先按免费按钮，下一步可以按梨诺终结。

无需把庄设为固定第一优先级。如果队友增益值得先插入，搜索可以选择`庄终结→梨诺终结→庄免费战技`，也可以选择其他收益更高的可执行路线。只执行当前首步，后项随下一真实观测重新计算，不锁死整张轴。

## 首次免费三请求的条件报价

新增明确的`nominal_free_salvo_including_current_requests`分支：免费技能确实先发出3位置请求，因此本次模型可假设这批请求赶上区域采样，并按N≥3估价；已有仍有效的名义请求可合计至原上限9。它不是初始库存补3，也不是白圈证明剑数或投射物已经到达。

`same_cast_requested_swords=3`与`same_cast_requests_reach_before_area_snapshot_assumed`显式记录这项相位假设；`arrival_unconfirmed/owner_range_unmeasured/untracked_initial_inventory_excluded`继续保留。实际库存不在预览时改变，接受后只登记一次新的3请求，失败不登记。无免费资格的普通战技不能借这条合同补3。

免费C0，不消费导电，也不新生产孤舟或壤流消费层。三剑完整名义齐射、孤舟终结有效、无其他增幅时，本次有效报价约211550.819；有已生效的梨诺高歌时，择高增幅与攻击提升后约248430.933。天地造化逐段20%/22%/24%参与，不能把最终24%乘给所有雷击。

完整强化齐射的名义输出区间跨过姿态到期时不计满伤，不仅检查0.55秒交接。自然到期后的按钮不保留此前免费/替换形态，普攻恢复基础时间。当前模型不延长未核准的退出延期。

## 多轮普攻与搜索边界

长窗口只重复实际已有主控的普通攻击候选，按每轮动作时间、个人锁、姿态和增幅期限重新估价；时间推进后才可以再安排下一轮。没有凭空生成未来SP、战技刷新或连携候选，战技/终结/连携仍只用本帧已知候选一次。普攻回SP未纳入后续预算，不用它虚构连续付费战技。

普通和强化路线都允许同样的重复普攻条件，避免开终结路线被多算、普通路线只给一轮。27.6秒路线和12秒路线总数不可直接当相同时间DPS比较。个人5秒天赋在普攻整链上使用全程有效的最低增幅，不倒灌后来才涨起的值。

长窗口beam宽度由16扩到64，避免零即时伤害的辅助开启动作被只看近期伤害的窄beam过早淘汰。仍是有界近似搜索，不声称全局最优。正常12秒模式保持原宽度16；没有新用户配置或检测循环。全终结电队合成暖测中宽64比宽16耗时更高，性能与完整实战响应仍需后续验证。

本机固定输入30轮暖测：无终结5候选/12秒/宽16，中位3.34ms、p95 3.90ms；全终结9候选/27.6秒/宽64，中位91.95ms、p95 263.67ms。仅规划器，不含截图、识别、首次加载和真实按键；不能当游戏响应实测。扩大的搜索有明确CPU成本，当前不声称已解决搜索性能。
