# 单位技力贡献与姿态结束动作

2026-10-19。ReleaseBurstPlanner增加首动作的SP边际贡献，并进入真实选招先后。它不取代预算、连携队首、角色锁、增益窗口及伤害可执行性。

## 计算口径

`BurstSpValue`保存本动作直接伤害、后续贡献、实际SP消耗与每SP贡献。对已搜索到的可行路径，移除首动作并按原时间安排重放其余动作；重新检查SP、个人动作锁、姿态解锁、白圈转移、机制来源和连携前置。不会把后面的连携当成已经清掉队首，也不把删掉终结后缺失免费资格的战技仍算作0SP。

```text
本动作边际贡献 = 原路径伤害 − 移除首动作后的可行后续伤害
后续贡献 = 本动作边际贡献 − 本动作直接伤害
每SP贡献 = 本动作边际贡献 ÷ 本动作实际SP消耗（仅当消耗>0）
```

梨诺25SP演唱本身直接报价0，其贡献来自实际能被增益覆盖的后续伤害增加，不会把队友整份基础伤害全归给梨诺。贡献只用于候选比较，不再加一次到路径总伤害，避免重复累计。非线性交互和队列解锁也可能包含在后续贡献中，不能将其全部称为单个buff伤害。

原搜索仍使用12秒局部窗口和当前可行候选。没有捏造60秒必定持续输出的受益人数、未来技力回复或未就绪技能；长时覆盖价值仍是独立缺口。

## 真正影响顺序

搜索先保留可执行整段产伤，等伤害时优先保留更多SP。在不牺牲该段产伤、不多花SP的可替换付费首动作中，再按每SP边际贡献排先后；时间、队列和角色锁继续适用。

例如两个可交换动作分别1500伤害/100SP、1000伤害/25SP，预算125且窗口能容纳二者时，总伤害2500不变，25SP动作按40伤害/SP先放。若辅助→输出明确有增益，不能为了让单个输出的比值更高而倒排这条依赖，导致确定的团队伤害下降。预算不足以同时施放时不信用未知的未来回复来虚构辅助收益。

首动作实际0SP时`damage_per_sp=null`，不返回Infinity，也不把SP成本改成任意1。真正免费战技、连携和终结继续按原有整段伤害、动画、能量可用与队列约束比较。首动作贡献依然记录。反事实贡献仅在有机会替换的候选上按需计算，不对全部搜索节点作多次重放。

## 姿态结束不是免费生产者

已跟踪的梨诺演唱/高歌有来源动作锁。战技候选生成、规划和最终执行三处都检查锁；姿态中结束按钮不会作为一个新的0SP增益动作入候选，也不会再刷新60秒。庄方宜姿态中的终结中止继续沿原禁止重当终结的合同。

这不新增未知姿态的检测。冷启动时尚未跟踪的姿态仍是观测缺口，不能只凭按钮价格0推导结束/开启。普通SP确认和返还时点不变。

## 验证

专项覆盖可交换付费先后、只计辅助边际增益、未知未来收益不补、梨诺0SP结束被锁、同角色锁、真免费有限报价及连携队首反事实。既有梨诺预算不足测试更新为只选择可行输出；预算足够仍先开团队增益。

真实step回归使用实际profile：队伍余烬/佩丽卡、200SP时选择佩丽卡并发出第二槽按键；日志直接伤害24472.4、后续贡献0、成本100、伤害/SP为244.724。梨诺/佩丽卡有125SP且能覆盖时，梨诺贡献为其新增的2447.2400伤害，25SP对应97.8896伤害/SP；不是把佩丽卡整次26919.6400全算作梨诺贡献。两例保留固定木桩与配装口径。
