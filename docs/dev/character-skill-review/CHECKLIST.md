## 全量校验项

- [ ] 技能描述与当前解包文本逐字或语义一致；
- [ ] `skill_type`、元素、角色名、技能顺序正确；
- [ ] `effects` 只含技能产出，不混入触发前提；
- [ ] `trigger_condition.effects` 只含依赖，不混入产出；
- [ ] `enhancement.effects` 只含条件新增效果；
- [ ] `target` 与描述一致；
- [ ] `count` 的正负与施加/消耗方向一致；
- [ ] `value` 不把布尔存在误写成数值倍率；
- [ ] `duration` 不臆造；
- [ ] `stagger_value` 与具体技能段对应；
- [ ] 强制异常与普通附着区分；
- [ ] 法术爆发与法术异常区分；
- [ ] 破防状态与破防层数区分；
- [ ] 重击、击飞、猛击三个概念区分；
- [ ] 失衡值、失衡状态与处决区分；
- [ ] 连携触发条件不误记为技能产出；
- [ ] 终结技能量与战技技力区分；
- [ ] 空角色文件有明确状态与后续来源。
