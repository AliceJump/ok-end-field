## 实际路径

TimedCombatLogic._configure_team创建ReleaseBurstPlanner，沿用fixed_damage_baseline的固定配装、潜能/等级和逐技能quote_basis；复用damage_release_rules中核准的释放来源，不从统计JSON或关键词任意生成buff。固定装备、常驻天赋/潜能不再次施加。

step在现有爆发起手及普通终结排序前，收集当前HUD已就绪的终结技、冷却/技力/存活/动作锁/爆发预留允许的战技。检查所有可用队员，避免常规循环子集排除受益角色。用12秒有限窗口比较动作顺序，实际消耗共享SP；不推定未来能量、额外释放次数、技力自然恢复或命中结果。成功释放的增益在预测副本中生效，使零直接伤害辅助也可因后续收益成为起手。保留每个起手的候选，避免按累计直接伤害剪枝时删除辅助起手。

预测有正增益贡献时，返回的第一个动作直接调用现有use_ult或_try_battle_token，影响实际按键。无匹配受益输出、技力不足或效果在后续报价前到期，不会由这条增益路径提前释放。现有原生模型诊断/匿名连携历史不阻塞这套受限释放报价；但原生stage及原编排的动作合法性检查仍保留，不借此宣布原生程序完整。

终结技use_ult成功返回后，战技沿用原有接受/技力确认后，才提交释放增益。失败返回不提交；相同确认不重复施加；同源刷新、独立计时及到期由TimedDamageState处理。未识别头像后来补全保留已接受的全队窗口。现有连携的就绪、释放和匿名处理不变，不启用连携增益生产，也不修改技力返还时机/HUD阈值。

## 伤害与属性数据流

每个报价读取自身元素/normal、skill、ultimate标签，使用完整固定面板作动态/静态伤害比。攻击提升按白攻击、已有攻击百分比、固定攻击和属性系数计算，不能把攻击+10%简单当总伤害+10%。增幅/增伤按现有计算器乘区处理，孤舟不增幅终结，熔铸火焰不增幅战技。

当前主控已有确认时，可加入一份基础普攻链预测尾项：rank_row_sum quote配原始普攻actionable时长提示。它用来评价普攻加成收益，不生成额外按键、等待锁或实际命中/完整连段证明；不将强化姿态倍率猜成基础普攻倍率，也不默认切换到终结释放者。后续实际终结HUD等待耗时被保存，用于下一轮窗口预算；每次step重新按当前可用动作计算。

已确认的最终力量/敏捷/智识/意志差值能通过TimedDamageState刷新/到期，并更新floor主副属性攻击系数和报价。本批新增的真实属性producer是秋栗攻击提升；没有新增四维百分比/转换producer，不把已有差值接口说成它们已闭合。
