# 01 · COMBAT_SYSTEM — 战斗基础循环与角色控制

> 调查日期：2026-09-24。可信度标记：`[已确认]`（多来源互证/官方WIKI）、`[社区测试]`（NGA/B站实测帖）、`[单源]`（仅一处来源）、`[未确认]`（需实测）。
> 本文目标读者：实现 Battle Simulator / Rotation Optimizer 的开发者。

## 1. 战斗基础框架

- 4 人小队同屏作战，仅操控 1 名**主控干员**；其余由 AI 控制（普攻欲望低，伤害低）。`[已确认]`
- 按 Q 切换下一名干员、F1-F4 直切 1-4 号位；切换时新旧主控**互换位置**，视角不变。`[社区测试]`
- 主控可执行：常态攻击（普攻+重击）、战技、闪避、打断、处决、连携技、终结技。`[已确认]`
- 非主控干员也可释放战技（按 1-4），**不打断主控行动**；有范围限制（离主控过远不可放）。`[社区测试]`
  - → 对编排器：可以「后台放战技」，前台持续普攻保证资源恢复效率。

## 2. 战斗生命周期（事件链）

```
进入战斗 → 技力重置 [社区测试：入场重置为2格/200点，待实测确认]
→ 普攻连段（N段）→ 末段=重击（回复技力+积累失衡值）
→ 战技（消耗100技力，无CD；命中→该干员获得终结能量）
→ 异常/状态积累（法术附着/物理破防层/失衡值）
→ 连携技条件满足 → 5秒窗口内按E释放（命中→获得终结能量）
→ 终结技能量满 → 释放终结技
→ 敌人失衡值满 → 失衡（无法行动、受伤×1.3）
→ 主控对失衡敌人的首次普攻 = 处决/终结攻击（大倍率+回复技力）
→ 敌人蓄力（红圈）→ 战技/连携/终结技命中可打断（+失衡值）
→ 死亡 / 战斗结束（脱战：技力快速回到200点）
```

`[已确认]` 各步骤来源：huijiwiki 分类:战斗、NGA 攻略帖交叉。

## 3. 普通攻击与重击

- 普攻为固定连段模组（3-5 段，本地 rank_stats 有 普攻第一~五段倍率），**没有短按/长按之分**，连段末段即重击。`[已确认]`
- 重击：更高倍率、回复技力、积累失衡值（本地数据：每角色重击失衡值，如噗切娜 21 点）。`[已确认]`
- 下落攻击：空中普攻派生，本地数据有「下落攻击倍率」。
- 处决攻击：对失衡敌人的首次普攻，本地数据有「处决攻击倍率」（如噗切娜 900%），并回复技力。`[已确认]`
- 闪避可取消普攻硬直，派生闪避追击；不消耗资源（闪避消耗体力，二段连闪）。`[社区测试]`
- 极限闪避（攻击判定瞬间闪避）：回复技力。`[单源，待实测]`

## 4. 战技（Battle Skill）

- **消耗 100 点技力**，无冷却；技力够就能放。`[已确认]`（huijiwiki：技力上限300点）
- 命中敌人时**该干员获得终结能量**。`[已确认]`
- 干员正在执行不可打断动作（如放终结技）时无法放战技。`[社区测试]`
- 数值：本地 `rank_stats` 每技能有「技力消耗」（30 个战技全部为 100 或角色特有值）、倍率、失衡值行。
- 部分战技返还技力（别礼 30、噗切娜 20+20、诀技力返还）。`[已确认]`（本地数据）

## 5. 连携技（Link Combo / QTE）

- 每干员有**独立触发条件**与**独立冷却**（数值差异大：弧光 5s、多数 15-20s、个别 40s；早期「普遍 ≤20s」「脱战重置」的说法未获证实）。例：大潘=敌人 4 层破防；噗切娜=主控受击后。`[已确认]`（独立条件与冷却）/ `[社区测试]`（数值范围）
- 条件满足后出现提示，**5 秒窗口期**内可按 E 释放；窗口内即使条件被消耗（如破防层被打掉）仍可释放。`[社区测试]`（窗口时长未获多源证实）
- 多个连携同时就绪时的释放顺序：有实测称**按编队顺序**决定优先级（B站 BV1L16iBfE4a）；早期「按触发先后排队」的说法与之一并存疑。`[社区测试]`
- 命中敌人：造成伤害 + 积累失衡值 + 获得终结能量。`[已确认]`
- → 对编排器：连携是**免费动作**（不消耗技力），应与增伤窗口（连击层数、脆弱）对齐。

## 6. 终结技（Ultimate）

- 每干员**独立能量条**；本地数据「所需终结技能量」（30 个战技行覆盖，典型 100 点）。
- 获取：战技命中、连携技命中、部分技能特效行「获得终结技能量」（卡缪等）；普攻/重击是否给能量 `[未确认]`。
- 释放为不可打断动作（动画锁）；释放后干员短期内无法放战技。`[社区测试]`
- PC 端长按战技键释放（就绪时）。`[社区测试]`

## 8. 打断与失衡（概述，详见 EFFECT_SYSTEM）

- 敌人蓄力（红圈预警）时，战技/连携/终结技命中 → 打断 + 额外失衡值。`[已确认]`
- 失衡值满 → 失衡数秒：无法行动、受伤 ×1.3（`[已确认]` 公式；攻略站流传的"+50%"与公式冲突，以 1.3 为准）。
- Boss 有失衡节点（部位命中产生僵直）。`[社区测试]`

## 9. 角色切换与后台

- 切人立即换位，无读取动画；被切下的干员转 AI。`[社区测试]`
- Buff/Debuff 在切人后是否保留、后台角色被动是否生效：`[未确认]`（需要逐 Buff 实测）。
- 释放非主控干员的战技不影响主控行动 → 「前台普攻 + 后台战技」是核心输出节奏。`[社区测试]`

## 10. 对 Rotation Optimizer 的关键影响

1. 资源轴：技力共享池（300 上限、12.5s/100 恢复速率）决定战技插入频率。
2. 能量轴：每角色独立终结能量，战技/连携命中是主要充能手段 →「先战技后大」的循环天然形成。
3. 失衡轴：把高倍率技能与连击层数、脆弱/易伤 Debuff 堆进失衡窗口（×1.3）；失衡后普攻接处决。
4. 连携轴：免费伤害 + 充能，条件触发型（如破防 4 层）→ 编排器需维护「异常层数 → 连携就绪」的事件队列。
5. 动画轴：伤害结算时间点、前后摇、取消窗口数据全部 `[未确认]`——这是当前最大数据缺口（见 ROTATION_REQUIREMENTS）。
