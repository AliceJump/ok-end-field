# 04 · EQUIPMENT_SYSTEM — 武器 / 装备 / 套装

> 装备结构 `[已确认]`（B站WIKI 装备图鉴精确数值）；词条归属乘区 `[已确认]`（DAMAGE_FORMULA 各区定义）；套装间冲突数值已标注。

## 1. 装备结构

```
武器（1）
├── 基础攻击力（并入攻击力公式的"武器攻击力"）
└── 词条（随精炼/等级成长，如"物理伤害+44.8%"、"恢复技力后全队物伤+"）
装备（4 件）：护甲 + 护手 + 配件 + 配件
├── 防御力（白值，例：护甲56 / 护手42 / 配件21）
├── 主属性（力量/敏捷/智识/意志 白值）
├── 主词条（百分比类，例：暴击率 10.4%、源石技艺强度 41）
└── 套装归属（同系 3 件触发套装效果；第 4 件常用散件）
```

- 4 件最高稀有度装备合计 140 DEF → 承伤倍率 0.416。`[已确认]`
- 装备制造系统产出原件，精锻/基质蚀刻后期成长。`[社区测试]`
- 装备本身词条**固定**（无随机副词条，NGA：「这游戏没有圣遗物」）；但**武器基质（Essence）是词条+蚀刻系统**：每颗基质 1 条定名技能词条 + 2 条随机词条（基础/附加属性），初始 +1~+4，蚀刻上限 基础/附加 +6、定名 +3。`[已确认]`（wiki.gg Essence 页 + 官方 WIKI 基质页 2026-09-24 抓取）
- **基质词条 = 武器技能等级提升**：注入与武器技能同名的词条即提升该技能等级（如「意志提升」词条提升武器的「意志提升·大」技能）；命名词缀（强攻/压制/追袭/粉碎/夜幕/迸发/附术/残暴/巧技/医疗/流转/切骨/昂扬/效益）同时是武器特殊特效的**触发扳机**（追袭=连携技触发、压制=战技触发、粉碎=重击触发、夜幕=终结技触发等）。`[已确认]`（wiki.gg + NGA tid=46293775）
- 满配武器技能 = 武器 90 级基础等级 + 基质词条满蚀刻（如 黄金时代「意志提升·大」3/9 + 基质 +6 = 9/9）。

## 5. Build 对比示例（同 Rotation 下）

```
装备A：+20% 攻击力词条           → 攻击区 +20%（受白值稀释）
装备B：对失衡目标伤害加成 59.1%   → 增伤区，但只在失衡窗口生效
装备C：终结技蓄能效率 24.6%       → 不加伤害，提高大招循环频率
```

- 常规循环：A > B；**失衡爆发循环**（配合 ×1.3 + 处决）：B > A。
- 编排器实现：装备建模为 `StatBlock（白值/主词条）+ SetBonus（条件触发 Buff）`，条件 Buff 走 EFFECT_SYSTEM 的 Trigger 模型（如"恢复技力后""施加燃烧后"）。

## 6. 对 Rotation Optimizer 的影响

1. 套装效果大多是**条件触发**（施加异常后/恢复技力后/暴击后）→ 时间轴模拟必须实现这些事件，否则套装收益全错。
2. 「对失衡目标伤害加成」与失衡窗口联动 → 选装时和失衡轴编排联合优化。
3. 充能效率词条改变终结技频率 → 影响连击层规划与能量轴。
4. 源石技艺强度只放大异常/反应 → 法术队堆、物理队无用。
