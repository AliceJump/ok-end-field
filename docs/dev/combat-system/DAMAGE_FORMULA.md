# 02 · DAMAGE_FORMULA — 完整伤害公式与全部乘区

> 可信度：公式骨架 `[已确认]`（huijiwiki 与 endfield.wiki.gg 逐字互证，NGA 数值学导论实测吻合）；单项数值另有标注。

## 1. 总公式

```
伤害 = 攻击力 × 基础倍率 × 伤害加成 × 暴击倍率 × 增幅倍率 × 连击倍率
       × 脆弱倍率 × 易伤倍率 × 固定伤害倍率 × 减伤倍率

固定伤害倍率 = 失衡倍率 × 终结倍率
减伤倍率     = 伤害减免倍率 × 庇护倍率 × 防御倍率 × 抗性倍率
```

- 所有数值按精确值（含小数）计算，显示时**向下取整**（99.6 → 99）。`[已确认]`
- **不同乘区之间全部乘算**；同一乘区内部按下方规则加算/乘算。NGA：「没有米家那种多乘区低数值+少乘区高数值的混合设计」。

## 2. 攻击力（Attack）

```
攻击力 = ( (干员攻击力 + 武器攻击力) × 攻击力百分比加成 + 攻击力固定加成 + 地区特殊加成 )
         × 属性加成
属性加成 = 1 + 0.005 × 主属性 + 0.002 × 副属性
```

`[已确认]`（huijiwiki/wiki.gg/NGA 三方一致）

- 百分比攻击（"攻击+x%"）**只作用于**干员+武器白值之和；固定攻击在乘区之后加算。`[已确认]`
- 主属性=力量/敏捷/智识（按角色），副属性=次属性。每点主属性 +0.5% 攻、副属性 +0.2% 攻。
- NGA 把「虚弱乘区 Π(1-虚弱)」归为攻击的子乘区；wiki.gg 将 弱化(Weaken) 列为独立乘区——**实现上等价**（都是 ×Π(1-x)），注意弱化降低的是「该单位造成的伤害」（对敌施加=敌输出下降）。`[已确认]`机制、归属 `[存在表述差异]`

## 3. 基础倍率（Base Multiplier）

分四类（NGA 实测汇总）`[社区测试，多帖一致]`：

| 伤害类别 | 公式 |
|---|---|
| 普通伤害（普攻/战技/终结技） | 技能面板倍率（×处决乘区见 §7） |
| 物理异常伤害 | 物理异常倍率 × (1 + 源石技艺强度/100) |
| 法术异常伤害 | 法术异常倍率 × (1 + 源石技艺强度/100) × 等级系数 |
| 法术爆发伤害 | 法术爆发倍率 × (1 + 源石技艺强度/100) × 等级系数 |

- **等级系数**：1 级 → 90 级从 1 线性增长到 1.5（即 `1 + 角色等级/180`）。`[社区测试]`
- 异常倍率表（见 EFFECT_SYSTEM §3）：与层数有关的倍率 ×(1+异常等级)，异常等级最高 4 → 最高 5 倍。

## 4. 伤害加成区（Multiplier Group / 增伤区）

```
伤害加成 = 1 + ∑伤害加成效果     （同类加算）
```

`[已确认]` 包含：元素伤害加成（物理/寒冷和电磁/灼热和自然分条目）、战技伤害加成、连携技伤害加成、终结技伤害加成、所有技能伤害加成、**对失衡敌人伤害加成**（注意：属于本区，不属于固定伤害倍率区）、长息套装"造成伤害+16%"。`[已确认]`（NGA 实测长息落增伤区）

装备主词条实测值示例（B站WIKI）：对失衡目标伤害加成 59.1%、连携技伤害加成 34.5%、终结技伤害加成 51.8%、寒冷和电磁伤害 23%。

## 5. 暴击倍率（Critical）

```
暴击倍率 = 1 + 暴击伤害（暴击时）；否则 1
期望伤害 = 伤害 × (1 + 暴击率 × 暴击伤害)
```

- 基础暴击率 **5%**，基础暴击伤害 **50%**。`[已确认]`
- **持续伤害（DoT）不能暴击**。`[已确认]`
- 上限：暴击率 100% `[社区测试]`；暴伤上限 `[未确认]`。

## 6. 增幅倍率（Amp）

```
增幅倍率 = 1 + ∑增幅加成     （同类加算）
```

- 仅法术四元素有：电磁增幅/灼热增幅/寒冷增幅/自然增幅（例：安塔尔终结技施加电磁+灼热增幅）。`[已确认]`
- **物理系没有增幅**（物理的对应物是碎甲 Breach 的物理受伤提升）。`[已确认]`

## 7. 固定伤害倍率区

### 失衡倍率
- 目标失衡中：**×1.3**；否则 ×1。`[已确认]`（huijiwiki + NGA + wiki.gg）

### 终结倍率（Finisher / 处决）
- 对失衡敌人的**首次普攻**变为终结攻击（处决）。`[已确认]`
- 按敌人阶层取固定值：普通 ×1.0 / 进阶 ×1.25 / 精英与阿尔法 ×1.5 / 领袖 ×1.75。`[已确认]`
- 本地数据另有每角色「处决攻击倍率」（普攻 rank_stats，如噗切娜 900%）——与终结倍率的关系（相乘/取大）`[未确认]`，P0 实测项。

## 8. 连击倍率（Link）

```
连击倍率 = 1 + 连击加成
```

| 层数 | 战技连击加成 | 终结技连击加成 |
|---|---|---|
| 1 | 30% | 20% |
| 2 | 45% | 30% |
| 3 | 60% | 40% |
| 4 | 75% | 50% |

`[已确认]`（huijiwiki 数值表 + NGA「战技30%/终结技20%」）层数可叠加，逐层收益递减；秋栗天赋可在大招期间给全队 +1 层。

## 9. 脆弱倍率（Susceptibility，元素脆弱）

```
脆弱倍率 = 1 + ∑脆弱效果     （同类加算，通常限定伤害类型）
```

- 例子：寒冷脆弱（别礼）、电磁脆弱/灼热脆弱（安塔尔）、物理脆弱（黎风战技/埃特拉连携）、法术脆弱（洁尔佩塔终结技、噗切娜终结技 2.5%×5s）、物理+法术脆弱（艾尔黛拉）。`[已确认]`

## 10. 易伤倍率（Increased DMG Taken）

```
易伤倍率 = 1 + ∑易伤效果     （同类加算）
```

- 描述为「受到的伤害+」且**不属于脆弱**的效果：导电、破防、管理员天赋「现实静滞」（物理受伤+10%）、塞希「启动进程」（寒冷受伤+7%）。`[已确认]`
- ⚠️ NGA 把「脆弱/受到伤害增加」并列为同一加算乘区；wiki.gg 拆为两个独立乘区。**实现时按两个独立乘区处理更贴近 wiki.gg；若实测发现同区则合并。`[存在冲突]`**

## 11. 减伤倍率区（承伤方）

### 伤害减免倍率
```
伤害减免倍率 = ∏(1 - 伤害减免效果)     （乘算）
```
装备「最终伤害减免」词条（生物辅助接驳器、纾难识别牌），适用于所有伤害类型（含超域 Æther 伤害）。`[已确认]`

### 庇护倍率（Protection）
```
庇护倍率 = 1 - max(所有庇护效果)     （只取最强，不叠加）
```
例：卡契尔战技 90% 庇护、噗切娜立盾 90% 庇护。`[已确认]`

### 防御力倍率（Defense）
```
DEF ≥ 0：防御倍率 = 100 / (DEF + 100)
DEF < 0：防御倍率 = 2 - 0.99^(-DEF)
```
- **干员初始 DEF=0；敌人固定 DEF=100，不随等级变化**（→ 平时防御倍率 0.5）。`[已确认]`
- 满稀有度 4 件装备 = 140 DEF → 倍率 0.416（减伤 58.33%）。`[已确认]`
- 防御来源稀少（装备、个别潜能如卡契尔+20）。破防/无视防御类效果如何进入该公式 `[未确认]`。

### 抗性倍率（Resistance）
```
敌人承伤：抗性倍率 = 100% - 敌方抗性%（+无视抗性）
干员承伤：物理抗性 = 100 - 100/(敏捷×0.001+1)；法术抗性 = 100 - 100/(智力×0.001+1)
```
- 敌人抗性以等级显示：D=0 / C=20 / B=50。`[已确认]`（huijiwiki）
- 腐蚀（自然反应）持续降低敌人全抗。`[已确认]`
- NGA：「抗性通常为 0.8 或 1」（即敌人常见 20% 抗或 0 抗）`[社区测试]`

- NGA 乘区列表另有「十一、伤害减免、十二、特殊（如连击）」——连击在 wiki.gg 版已是独立乘区（§8）；「特殊乘区」即固定伤害倍率区。
- 攻略站（endfieldguide 等）流传的 `DEF/(DEF+500+Level×10)` 公式与本页公式冲突，**采信 huijiwiki/wiki.gg 版**（多来源互证+NGA 实测）。
- 超域（Æther）伤害：仅在伤害减免词条中提及的独立伤害类型，具体规则 `[未确认]`。

## 13. 对 Rotation Optimizer 的影响

1. **乘区均衡**：新乘区从 1.0 起步收益最大——编排器应保证「攻击→增伤→暴击→增幅→易伤/脆弱→连击」各至少有一层来源，再谈堆叠。
2. **失衡窗口**：×1.3 + 对失衡伤害加成词条 + 处决倍率，全部只在失衡期生效 → 爆发技能应对齐失衡窗口。
3. **连击管理**：战技连击 30%→75% 是全公式最便宜的独立乘区——先用低倍率战技叠连击、再放终结技吃高层数。
4. **敌 DEF 恒 100**：防御倍率恒 0.5（无减防时），所有技能同吃；破防/腐蚀（减防减抗）是队伍级增伤，优先级高于角色自身小词条。
5. **期望伤害 vs 实际**：暴击期望 ×(1+CR×CD)；模拟器应同时输出期望与分布。
