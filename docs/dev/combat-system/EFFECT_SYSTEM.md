> 元素规则 `[已确认]`（GameWith、Mobalytics、game8、huijiwiki 四源一致）；异常倍率数值 `[社区测试]`（NGA 数值学导论）；Tick 细节 `[未确认]`。

## 1. 五种伤害类型

| 类型 | 类别 | 颜色 | 附着产物 |
|---|---|---|---|
| 物理 Physical | 独立 | 白 | 破防层（Vulnerable）→ 物理异常 |
| 灼热 Heat | 法术 | 红 | 灼热附着 → 燃烧 |
| 电磁 Electric | 法术 | 黄 | 电磁附着 → 导电 |
| 寒冷 Cryo | 法术 | 青 | 寒冷附着 → 固结/冻结 |
| 自然 Nature | 法术 | 绿 | 自然附着 → 腐蚀 |

- 法术附着（Arts Infliction）与物理破防（Vulnerable）**相互独立、可共存**。`[已确认]`
- 本仓库 effects.py 对应：`ATTACH_NATURAL`/`ATTACH_COLD`（附着）、`STATUS_CORROSION`/`STATUS_FROZEN`/`STATUS_CONDUCTING`/`STATUS_BURNING`（法术异常）、`STATUS_SHRED`/`STATUS_SHATTER`/`STATUS_HEAVY_STRIKE`/`STATUS_KNOCKDOWN`/`STATUS_HEAVY_HIT`（物理链）、`STATUS_BROKEN`（碎冰 Shatter——枚举名带历史包袱，官方名与多语言表均为「碎冰」，勿删）。

## 2. 法术附着 / 元素爆发 / 元素反应

- **附着**：法术伤害命中施加对应元素附着，持续 20 秒，同元素再施加刷新计时；单元素最多 **4 层**（= 状态等级 I~IV）。`[已确认]`
- **元素爆发（Arts Burst）**：对已有同元素附着的敌人再施加同元素 → 造成一次该元素法术伤害 + 加 1 层（至 4 层封顶）。`[已确认]`
- **元素反应（Arts Reaction）**：对已有 A 元素附着的敌人施加 B 元素（B≠A）→ 触发反应，**消耗全部已有附着层数**；**后施加的元素决定反应类型，已有元素的层数决定强度等级**。`[已确认]`
  - → 对编排器：先手元素叠到 4 层，再由触发元素打出最高等级反应，是法术队的核心循环。

### 反应组合表

| 已有附着 | 新施加 | 反应 | 效果 |
|---|---|---|---|
| 任意非灼热 | 灼热 | **燃烧 Combustion** | 灼热 DoT，基于触发者攻击力 |
| 任意非电磁 | 电磁 | **导电 Electrification** | 敌人受到的法术伤害+（易伤区） |
| 任意非寒冷 | 寒冷 | **固结 Solidification** | 无法移动（仅中小型敌人） |
| 任意非自然 | 自然 | **腐蚀 Corrosion** | 全抗性持续降低 |
| 固结中 | 物理状态/破防 | **碎冰 Shatter** | 大量物理伤害，结束固结（本仓库效果 ID：`STATUS_BROKEN`，术语「碎冰」） |

`[已确认]`；反应本身的伤害倍率见 §4；反应是否有内部 CD `[未确认]`。

## 3. 物理异常（Vulnerable 链）

- 物理技能首次命中 → 施加**破防（Vulnerable）**而非实际物理异常；破防最多 4 层。`[已确认]`
- 对已有破防的敌人施加物理异常，效果按类型分化：`[已确认]`

| 物理异常 | 对破防敌人的效果 |
|---|---|
| 击飞 Lift | +1 层破防 + 失衡值 + 浮空（浮空时间本地数据有行） |
| 倒地 Knock Down | +1 层破防 + 失衡值 + 倒地 |
| 猛击 Crush | **消耗全部破防层**，按层数造成大量物理伤害 |
| 碎甲 Breach | **消耗全部破防层**，按层数使敌人受到的物理伤害+（持续） |
| （对固结敌人） | 触发碎冰 Shatter |

- 本地 allowlist `_SHRED_STACK_PRODUCERS` 把 破防/重击/击飞/倒地/碎甲/猛击 视为同一条「物理强化链」。
- 连携技与消耗联动：大潘连携=敌人 4 层破防时触发并消耗之；骏卫连携=破防层数被消耗时触发。`[已确认]`（本地数据）
- → 对编排器：破防层既是伤害资源也是连携触发器——消耗时机的规划要同时算两笔账。

## 4. 异常伤害倍率表（NGA 实测）

与层数无关的（固定倍率）：

| 异常 | 倍率 |
|---|---|
| 击飞 / 倒地 | 120% |
| 冻结（固结相关） | 130% |
| 法术爆发 | 160% |
| 碎冰 | 120% |

与层数有关的（倍率 × (1+异常等级)，最高 5 倍）：

| 异常 | 基础倍率 |
|---|---|
| 碎甲 | 50% |
| 猛击 | 150% |
| 导电 / 腐蚀 / 燃烧（触发） | 80% |
| 燃烧（持续 tick） | 12% |

- 法术异常/爆发伤害 = 倍率 × (1 + 源石技艺强度/100) × 等级系数（1→90级线性 1→1.5）。`[社区测试]`
- 异常伤害走 DAMAGE_FORMULA 的完整乘区（暴击区除外——DoT 不能暴击）。`[已确认]` 机制 / `[社区测试]` 细节
- DoT：tick 间隔、是否快照施法者面板、能否叠加刷新 `[未确认]`（P1 实测项）。

## 6. 触发器（Trigger）模型

把技能描述中的条件句统一建模为 `Event → Condition → Effect → CD → Duration → Stack`：

| 触发词示例（本地数据实测存在） | 事件 |
|---|---|
| 主控干员受到攻击后可以发动（噗切娜连携） | 主控受击 |
| 敌人身上有 4 层破防时（大潘连携） | 异常层数阈值 |
| 破防层数被消耗时（骏卫连携） | 异常被消费 |
| 立盾期间首次成功格挡后（噗切娜战技） | 格挡事件 |
| 生命值已满的干员下一次受到的伤害降低50%（噗切娜天赋） | 满血+承伤 |
| 施加燃烧后/施加腐蚀后（动火套装） | 施加异常 |
| 通过技能恢复技力后（拓荒/长息套装） | 技力恢复事件 |

- 本仓库 `enhancements[].trigger_condition`（all/any 效果组）即静态可解析子集；文本类触发条件需手写规则库。

## 7. 对 Rotation Optimizer 的影响

1. **法术队**：最优循环 = A 元素叠 4 层 → B 元素触发高等级反应 → 重新叠层；同元素连打只拿 Burst（低效）。
2. **物理队**：破防 4 层 → 猛击（爆发）或碎甲（物理易伤窗口）；击飞/倒地提供控制+失衡。
3. **冻结连招**：固结 → 物理碎冰，是全游戏最高单发倍率组合之一（法术爆发 160%×等级系数 + 碎冰 120%）。
4. **失衡窗口对齐**：×1.3 + 对失衡增伤词条 + 处决，全部塞进失衡期。
5. 反应消耗附着 → 编排器必须把「附着层数」作为队伍共享状态模拟（类似技力池）。
