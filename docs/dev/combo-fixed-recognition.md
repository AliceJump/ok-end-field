# 固定槽位连携头像识别

2026-10-16 顺序提示续作：见 [战斗内连携顺序表](combo-order-memory.md)。队首仍完整匹配当前队伍，后续槽可使用已观察的相对顺序缩小候选；未知槽仍独立识别。下面的原始全队阈值适用于 `match_scope=team`，顺序缩小结果另有更严格阈值和定期完整核验，不能把其 margin 当作全队差值。

基于 master b5770cad 独立实现识别层，不依赖 PR #489。BattleMixin.observe_link_skills() 先沿用 default_link_skill 的现有默认小框，再只读取当前队伍候选的圆头像；最多四槽、互相独立，未识别项保留原槽位，不短路或把后面的角色补到前面。

use_link_skill() 在原就绪检查通过后、原按E之前真实调用识别接口，保存 link_skill_observation。按键尝试后清理身份缓存，下一次重新读取；未知队伍/头像或资源不可用时保留原匿名E路径。也可在编排前显式调用只读 observe_link_skills(team=...) 获取快照；本PR不修改连携伤害排序、冷却、buff、技力、释放确认或匿名时间轴。头像结果不代表已经释放、命中或某个具体替换技能；队首只能读position=1，不能把后续已识别头像提升为队首。

## 几何与匹配

1920×1080 基准下四框如下，端点为半开区间。仅使用框内脸部的不透明稳定区域，避开圆环和右下角技能徽记。第一槽头像控件按83像素、其他槽61像素渲染，模板预先缓存；匹配仅在固定框内部允许±3像素平移，无SIFT、宽HUD/整排搜索、Hough圆环硬门槛或逐帧全35头像搜索。

| 槽位 | 固定框 (x1,y1,x2,y2) | 依据 |
| --- | --- | --- |
| 1 | 1134,450,1223,539 | 现有三人实拍队首 |
| 2 | 1228,470,1294,536 | 现有实拍 |
| 3 | 1299,470,1365,536 | 现有实拍 |
| 4 | 1370,470,1436,536 | 用户批准按2/3槽71像素公差外推，待四人实拍 |

分辨率变换采用与现有就绪图标一致的均匀缩放、水平/垂直中心锚定。合成测试覆盖缩放和超宽坐标；尚无其他布局/画布设置的现场验证。布局不匹配时允许未知，不扩大搜索框猜测。

使用带前景mask的灰度 TM_CCOEFF_NORMED，最佳分数≥0.80且与其他角色次佳差≥0.08才返回身份。分数不是概率。管理员男/女头像分别保存native_id，映射同一“管理员”；角色次佳差不把男女变体当不同角色竞争。编队检测保留实际命中的男女模板名，最近2.5秒、尺寸及已知队伍成员一致时，直接把管理员连携候选缩小到对应性别，不另扫编队；性别未知、来源过期/失败/换队时保留两种候选，不猜性别。该约束变化也会清理身份缓存。当前队伍未知部分不补全35人扫描，重复/冲突角色不能给出唯一team_slot。

只在队伍、尺寸和槽内脸部像素完全相同的情况下复用缓存，队伍/尺寸变化、提示关闭或按E后失效。头像内容改变，即使槽数/位置相同也重新匹配；缓存不能仅靠时间或圆环数量续命。

快照包含observed_at（本机采样时间，不是引擎精确时间）、team、frame_size、ready，以及四个position/box/character/native_id/team_slot/score/margin。未识别可能是空槽、遮挡、动画或未知；不提供“确定不存在”。ready仅复用现有通用提示检测，不等于逐角色canCast。灰色头像仍可识别，但不从亮度推禁用原因；圆环短残弧曾漏检，因此不能先判“无环”就禁止查头像。剩余秒数尚未接入，避免将启发式估计作为硬截止。

## 素材来源与复现

assets/data/combo_portraits 保存一个35张原生圆头像有效区域组成的RGBA图集和索引，不包含研究工具、完整Unity资产或实拍截图。来源为2026-10-15已核验VFS5客户端本地采集；索引保留原资源路径、VFS路径hash、bundle摘要、导出PNG摘要和atlas摘要，映射当前33角色（含男女管理员）。额外本地角色素材不自动成为未知队员候选。运行时不导入研究包，首次需要识别时才加载校验图集。

使用仓库锁定环境复现产品图集：

```powershell
uv run --locked python scripts/skill-data/export_combo_portraits.py --source <已核验主仓忽略目录中的chain-contact采集目录>
```

原始解包、机器码、实验脚本和实拍验证日志全部保留在主仓忽略目录，不混入本PR。当前范围是固定区域识别及原按键路径采样；释放身份确认、精确计时、伤害决策接入应另按有效证据推进。

导出输入限定主仓忽略的tmp采集目录，输出限定产品图集或本工作树tmp/combo-portrait-reexport；资源/输出文件的解析路径必须位于所选目录内，拒绝父目录越界和符号链接逃逸。
