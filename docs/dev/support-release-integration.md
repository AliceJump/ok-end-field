## 本地证据与属性边界

导出器直接读取本地已解包、哈希校验的 SkillTimingStore 记录、等级 blackboard、canonical 描述和选中潜能。scripts/skill-data/reviewed_support_release.py 是导出时的独立审核边界，主循环不加载原生库。support-evidence.json 保存原生记录摘要、查询节点、帧、等级参数、潜能修正、固定配装、原始属性值及来源摘要；index.json 另校验该文件与导出脚本摘要。改等级、潜能、武器、四件配装或原生审核块必须重审，不能自动放行。

赛希 buff_chr_0011_seraph_atk_buff 的 StoreAttributeValue 为属性41、FinalNonConverted=1、Source、useFloor=false。梨诺第22块的 StoreAttributeValue 同样为 FinalNonConverted，属性42、Source、useFloor=false，先按 will_max 限幅，再把 fnlatk_up 传给音乐姿态。不能把普通面板域作为任意战斗状态下的该查询输出。

本层明确使用 fixed_build_projection_without_dynamic_four_stats_or_conversions：只对当前选中固定配装和未触发临时四维/转换状态进行报价，沿用原固定面板基线。检查选中被动不存在这项属性的条件/转换修饰，四维原始值保留小数；既有全队攻击和伤害加成不改变这两个输入。这里没有向研究 CombatWorldState 填入 FinalNonConverted，没有证明全角色属性初始化、百分比组件或动态转换 producer 完成。研究分支原有“真实非转换属性生产者待补”项继续保留；更换配装和加入动态四维时必须重新建立输入合同，不能拿当前常量推广。

## 梨诺实际团队与清理链

buff_chr_0035_liino_ultskill_music_tag 使用 auraType=1、无空间形状、Character对象过滤、checkAlive=true，向其他队员提供攻击/增幅父buff；本人通过独立 child 获得对应收益。治疗/天赋庇护仍有空间范围，未被混算进全队伤害规则。攻击最终落到 attributeType=2、formulaItem=6；增幅 child 使用 EnhancedAction 的电磁/自然 subtype。父姿态结束撤掉各 child，禁用的结束后续buff不计额外尾窗。

预测和实际报价从77/30秒开始，到77/30+15秒结束。同源重复确认去重、重新释放刷新；来源下一次已接受动作撤销姿态收益，来源槽位已被既有逻辑禁用时撤销仅依赖来源姿态的窗口。团队普通定时增益不随这个清理一起移除。未添加死亡、击中、属性或buff识别器，也不推定用户手动中止/游戏外部中断已经被检测到。

梨诺自己的基础战技在姿态中已变成中止按钮，故预测和实际 _try_battle_token 都阻止把它作为输出；她的普攻不作为高歌期间受益动作。其他角色可在跨角色 handoff 后输出，无须等梨诺18秒完整动作锁结束；本人仍保留同角色 actionable 锁。既有匿名连携释放处理保持不变，不靠匿名E确定连携角色或额外补能。

梨诺终结的持续脉冲、结束爆炸和倍率行之和不能放在起手时刻统一计价。本层将她终结作为零直接伤害的辅助起手，仍计个人终结就绪及动画时间，通过队友后续增益决定是否插入；旧 master 总伤害不能通过 value 参数绕回这份即时报价。持续攻击、命中和结束爆炸的完整伤害执行留在后续机制台账。
