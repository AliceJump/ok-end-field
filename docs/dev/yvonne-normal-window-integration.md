不证明实际命中、冻结或引擎逐帧执行。每次投射物的暴击层数、4秒刷新、满层暴伤、
终结攻击的冻结分支分别计算；冻结额外伤害和冰点天赋不加给此前全部子弹。

队友动作计入中断时间，保留尚未到期层数；中断后从首段重启是保守模型策略，
不是已证明的原生输入回放。逐段按增幅窗口定价，不把短增幅覆盖整段。
未开启姿态时不供应强化普攻；释放失败不安装窗口，过期/来源失效清理。

1～4人共用现有搜索及机会成本比较。普通攻击状态参与快速表键，表算法摘要包含
新报价代码；命中缓存仍重放动作约束。不会把伊冯终结单独另存成不参与排序的数据集。
