# 固定配装定稿（2026-10-07）

定稿四件写在 `scripts/skill-data/generate_character_builds.py` 的 `CURATED_BUILDS`，由生成器写入 `assets/data/character_builds/*.json`，再重算 damage_baseline.json（固定面板在另一分支另行重算）。

## 1. 规则

- 每名干员固定 4 件：护甲 1、护手 1、配件 2。同名配件可以装两件（如险关通信器×2）。
- 至少 3 件属于同一个有套装效果的套组；纾难、涉渊等“无套组技能”的套组不计。
- 第 4 件为自由件，按干员特性选择。
- 生成器校验：件名存在于 `equipments.json`、部位顺序为护甲/护手/配件/配件、存在 3 件同套。

## 2. 旧数据的问题

- 官方配装来自“装备页推荐干员”反查，只能得到不重复的件，表达不了双配件，所以 22 人只有 3 件。
- 新套装（如险关）没有回填推荐干员，且旧标签树缺套装名，`equipments.json` 里险关的 `set` 为空。
- 部分官方反查结果与当前版本脱节，例如萤石、提弗洛斯的自由件是寒冷电磁加成，萤石的拓荒供氧栓是意志/物理件。

## 3. 证据优先级

1. 社区共识充分（EndSync 汇总中主流套装至少 3 套、完全相同四件至少 2 套）：采用社区主推四件。
2. 社区样本不足：取两个以上独立来源（EndSync、GameKee、TapTap、mrfzzmd、ldcapple 等）的共同核心件。
3. 仍无共识：保留官方推荐件，用同套配件补齐第 4 件。

EndSync 页面：`https://endsync.vercel.app/zh/wiki/<slug>/`。“A/B”表示该套装出现在 B 套配装中的 A 套。
