# 伊冯终结普攻窗口报价（2026-10-21）

本层把冷冻射手作为一个名义持续输出窗口，已经进入研究分支 `ReleaseBurstPlanner` 与真实 `TimedCombatLogic.step`，不是另存一份角色数据。只调用原终结按键和已有持续普攻；不逐发发键、不新增命中/层数/冻结识别，也未修改PR #489或master。

## 报价边界与输入

当前固定配装为90级、技能12、P0、满级天赋。攻击4112.6539625，基础暴击率56.5%、暴伤50%，寒冷普通攻击固定增伤92.6%。面板中的装备、属性和常驻加成不再动态重复挂载。

窗口采用“单个静止目标、持续按住普攻、主路径续招、发射帧投影”的模型合同。它是排轴收益预测，不是已观察到的命中/发数、真实弹道耗时或完整原生输入模拟。未确认的其他攻击变体和条件天赋不会被拼进整段；不假定目标在整个窗口持续冻结。

所用等级表输入：7秒姿态，单发20%，结束重击300%，满足冻结条件时额外600%；每层暴击率3%、最多10层，满层暴伤+60%。这直接消费已审核的等级/技能效果。原生formulaItem5、ComboCache、SwitchMode及IFix的完整执行尚未闭合，不能因为本层可报价就提高原生程序覆盖。

上述节奏下完整窗口生成73个普通投射物报价事件、一次结束重击，基础总倍率约1760%；不是宣称实战每次必定打出73发。结束重击在姿态结束后第28帧投影到施放后9.966667秒；自身恢复期另外保留，不把重击首次造成伤害当作角色所有后摇已结束。

每一段按照当时的累计层数、固定面板和有效队友增益计算；第一发不是满层。实例投影保留四秒层数刷新寿命，中断过长后清掉过期层数。新确认的其他技能会暂停该段输出机会，在动作恢复后重启保守的主路径尾段，并保留仍有效的预测层数。不是声称引擎实际把普攻动画重置到第一段。跨终结继承的旧层数仍不自动推定，新的名义窗口从零层开始；显式初始层数/期限接口与实战已观测值分开。

用显式注入的20%寒冷增幅验证同一消费者（不是新增辅助角色规则）：若覆盖整段，报价314189.46；若只有施放起最初4秒，报价265681.27。只加给投影时点仍有效的部分，不把整段乘一次增幅。

当前主控已确认伊冯、相同12秒截止、不预设冻结时：不开大连续普通普攻约100036.45；开大窗口加恢复后的普通普攻约268632.58，因此新增收益约168596.13。已经存在的队友增益会同时保留在两种方案中，不能在不开大的对照里删掉它、只给开大方案加分。普通攻击机会成本使用既有整链的名义均速，不能当实际每发伤害或输入精度。

## 如何影响排轴

1. 就绪终结仍支付个人能量、动画和角色动作锁；原终结汇总9.2倍报价被替换为零即时伤害，由后续窗口承担输出，避免起手重复计算。周期日志也不把未来普攻预记为当场终结伤害。
2. 搜索分支比较当前就绪技能、队友释放增益和后续持续普攻。伊冯终结分支能预测自身成为主控；已接受窗口的持续输出只由既有主控观测确认本人后供应，禁用/动作锁槽位不供应该收益。
3. 同一搜索截止内，另算“不放终结继续普通普攻”的机会成本，使用已有普通整链报价/名义时长，并按增益到期拆段。窗口结束、重击自身恢复后也补同一截止内的普通普攻尾项；因此gain不是把完整26.18万全当新增收益。
4. 若继续普攻优于插招，返回持有普攻的真实决策，阻止落回旧终结/战技兜底。高收益队友技能仍能插入；没有全队七秒硬锁，也不会因为零SP普攻而无限新增候选。
5. 失败施放不提交窗口，重复确认不重开，换队只保留相同槽位角色，期限到后清理。按已知时间截取剩余攻击，不能把已过去的输出再次计入。

匿名连携保留研究树原有就绪/E合同，不把身份未知的伤害当零而静默压掉。其接受后只按既有保守时间保护扣除普攻机会，不推定具体角色、资源或连携buff。#489现有实名连携等工作仍是独立线，未为本层混入。

## 验证及保留项

专项包含逐层暴击、满层暴伤、结束/冻结分支、短增益覆盖、提前停止、长中断过期、普通输出机会成本、1～4人槽位、预测隔离、实际step开大/持续普攻/匿名连携与失败不提交。12份当前捕获的技能/buff消费者字段另行重核；脚本、JSON和日志仅留主仓忽略目录。

报价样本由既有哈希校验快照、等级表和技能效果生成。缓存的是最多128份时序样本，不预生成所有队伍或状态组合，没有新增大型二进制数据文件。实际引擎输入仲裁、弹道到达时刻、其他普攻变体、跨终结层数继承和完整原生属性重载仍是后续项；本层不能称整套机制或实战验证完成。

相同层数、同一增益/属性期间的投射物合并计算，原始事件轨迹仍保留；不跨增益到期合并。1～4人暖态、3/5/7/9个候选的搜索中位约1.19/13.69/34.85/38.86毫秒（各7次）；只是本机无截图的搜索样本，排除首载和游戏实战，可能受并行回归负载影响，不作为端到端延迟保证。
