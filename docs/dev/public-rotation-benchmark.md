# Prydwen 排轴对照：莱万汀队

2026-10-02，在本地 `codex/timing-dps-rotation` 分支检查。参考 [Prydwen 莱万汀攻略](https://www.prydwen.gg/arknights-endfield/characters/laevatain/) 的 Single Target Team，队位统一为莱万汀、狼卫、安塔尔、艾尔黛拉。选择它是因为有明确开场轴、后续循环及终结技操作说明；没有验证该站流量排名。

## 测试范围

已完成同队的本地模型计算，以及直接运行 `TimedCombatLogic.step()` 的离线 HUD 回放。回放只模拟已接受按键、技力消耗和名义自然恢复，没有敌人、伤害、真实普攻命中、额外技力或终结技能量。结果不能叫实战 DPS，也没有计算 Prydwen 完整轴的总伤害或真实周期。

客户端成功启动并进入游戏。浏览了干员列表及当前活动，没有找到莱万汀或她的试用入口，因此没有完成这支队伍的游戏内 A/B。用户选择自行准备队伍及练习关卡；此后停止操作客户端。

## 站点轴与当前方案

站点开场包含三次战技、两次重击和四次连携。其重点是通过队友附着、重击吸收及连携攒满四层熔火，再使用强化战技；后续还要管理充能、支援效果和终结技期间的普攻。这些前置动作是伤害成立的条件。

当前优化器只对战技有序子集计分。相同 8 SP/s 假设下：

| 本地候选 | 战技队位 | 稳定期窗口 | 预计战技伤害 | 战技增量 DPS |
| --- | --- | ---: | ---: | ---: |
| 原伤害按钮的四人顺序 | 1、2、4、3 | 50.0 s | 158,185.4 | 3,163.7 |
| 当前优化器 | 1、3、4 | 37.5 s | 124,360.8 | 3,316.3 |

模型提高 4.82%，但**这两行都是本地候选，第一行也不是 Prydwen 的轴**。不能据此说超过站点或实战提升。

差异有四项：

- 优化器删除了狼卫，尚未计入其对附着、熔火和充能的贡献。
- 莱万汀战技报价为 107,608.3，倍率 924% 含四层熔火追加攻击；`DamageQuote.requires` 为空，零层开场也能计入这份伤害。当前条件模型只支持部分附着，无法表示熔火。
- 安塔尔和艾尔黛拉被每轮保留，却没有按支援持续时间安排刷新，也没有给主输出的增伤收益计价。终结技按自身伤害/时间排序同样不能表示支援对齐。
- 保护窗口取完整 SkillData 时长，普攻仅在保护解除后输入。完整特效/技能轨道是否等于不能输入普攻的时间尚未校准。

## 执行回放结果

180 秒回放，30 Hz，开局 300 SP，8 SP/s，所有战技接受，无连携和终结技：

- 开场 `1@0.000s → 3@9.433s → 4@13.067s`，没有显式重击或攒层阶段。
- 最后两个完整循环均为 37.5 秒，说明名义技力稳定期可以重复；这只能验证资源与调度时间。
- 180 秒中按住普攻 38.5 秒，占 21.4%。其余时间是保护或技能输入，本回放不判断角色实际攻击次数。
- 单独注入莱万汀终结技保护状态，在没有其他就绪技能时，首次恢复普攻输入为 8.2 秒。原生轨道时长 8.167 秒，exclusive 2.433 秒。二者相差约 5.73 秒，但 exclusive 也不能未经验证就直接用作普攻恢复时间。

以上是当前执行器的离线输入行为，伤害字段明确为空。原生帧数暂按 30 FPS 换算；未测攻速、时停和实际可接续边界。

## 复现

```powershell
uv run --locked python -X utf8 scripts/skill-data/benchmark_public_rotation.py --output tmp/rotation-benchmark/prydwen-laevatain.json
uv run --locked python -X utf8 scripts/skill-data/benchmark_public_rotation.py --regen 6
uv run --locked python -X utf8 scripts/skill-data/benchmark_public_rotation.py --regen 10
```

脚本调用当前分支的规划器和执行器，不向客户端输入。JSON 含候选、原始伤害报价、首批按键时刻、循环窗口和保护回放结果。

## 待做的实战对照

用户准备好同队与可重复关卡后，固定配装、敌人、开场 SP/能量、主控和操作规则。分别运行站点轴与当前模式，交替多次，记录完整循环时间、击杀时间、熔火及充能、关键技能接受情况；关卡有可靠伤害统计才报告实际 DPS。开局爆发与稳定循环分开。

当前结果已足以否定“战技模型涨 4.82% 就是全队实战涨 4.82%”。下一步先补强化前置状态、普攻/重击接续边界和支援收益，再判断优化器是否有实战价值。本次只记录问题，没有修改战斗策略。
