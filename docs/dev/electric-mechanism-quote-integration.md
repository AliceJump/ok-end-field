## 数据与调用链

`reviewed_mechanism_quotes.py`在固定研究来源`cc9b471b50cdd6bc8b3a148b4eca93deef4efa02`核准12份原生记录摘要、技能12级参数、剑末击六倍和雷枪生成入口/子技能。与旧面板相同的导出流程在两位角色上增加独立mechanism合同；其他角色为null，原33面板、16增益规则、132基础报价与庄姿态不改。


运行时校验合同所有原生摘要及白圈条件摘要。旧按钮变体或其他角色亮圈不能套用这份分支。模型产生的请求不是观测，白圈也不变成精确库存；初始剑数、普通/强枪数不初始化为0。

## 庄方宜

| 输入或事件 | 本批处理 |
| --- | --- |
| 终结接受 | 既有25秒名义姿态及一次免费资格；不在此刻加三剑 |
| 首次免费战技接受 | 记录三位置生成请求，不回填本次施放快照，导电参与值为0 |
| 已跟踪的免费资格用掉/姿态到期且绑定白圈亮 | 仅在战斗模型中排除免费OR分支，按用户批准最低导电1级估价，不写全局敌人状态 |
| 战斗中途接管，未跟踪过终结/免费资格 | 亮圈仍保留免费OR导电歧义，不以缺记录证明免费不存在；不提前推最低导电或生成数量 |
| 已有来源请求且仍在报价期内 | 允许后续动作条件性采用名义剑数，标记arrival_unconfirmed、owner_range_unmeasured、untracked_inventory_excluded |
| 无历史/白圈暗或未知 | 保留单雷报价，完整剑数未知，不填三剑或九剑 |
| 普通/强化战技接受 | 已有剑不全量消费；最低导电分支按C+1、上限3记录新的名义请求，整体名义数量夹到9 |
| 到期或来源槽位失效 | 到期请求不再可报价，来源失效清除该来源记录，队友动作不清理 |

生成入口分别是普通6帧、强化5帧；这些是已核准的请求启动时间，不是0.2秒到达证明。36秒是本批从请求启动计的保守名义报价期，不能称实际实体寿命起点已观测。当前名义请求保持requested，尚不自动转成observed-arrived。

普通与强化分别使用导出的每雷参数和末击六倍，float32计算每雷及末击，再按当前固定面板报价。完整名义值只使用之前动作产生的请求，不把当前请求当已经采样的EntityBB_SwordNum。普通实际目标/落点、区域创建快照、tick/Jump和命中仍是报价假设。

真实回归：给定终结已接受，首次免费战技由有效白色消失接受后，后续白圈再亮时，三剑历史与最低一级导电使强化战技名义基础约142751，孤舟终结窗口计入后约209787；实际候选、排序和防溢出均使用该值。无历史的首次免费仍只计单雷约21455（含孤舟），不是自动完整171644；本次三剑是否赶上本次区域快照仍未证明。

## 艾维文娜

| 输入或事件 | 本批处理 |

| 绑定白圈亮，无历史 | 查询条件和召回的Owner/类型512/枪tag筛选已对应，按普通/强枪每份伤害较低者计最低一份名义回收；枪种和数量仍null |

“最低一份”只是名义伤害分量，并不声称有效命中一枪；原条件的excludeDeadEntity/containsHittableTarget并未证明命中。一次召回接受后，该最低证据不能无限复用，需观察到false后再次亮或有新producer。没有用截图识别枪种。两次同类生成的替换/并存未完整核准，本批保守只给最新一批同类型计价，历史不据此冒充全量库存。

## 连携武器与下一战技快照

固定来源的next_skill_sets.json核准碾骨三件套实际等级参数（0.3000000119/层、上限2）和三份原生buff。父监听SkillType=6；pending监听SkillType=2，实际层数快照→乘dmg_up→创建同cast增伤→finishAll。导出器核该顺序及完整来源摘要，15%常驻攻击不再加第二次。

模型仅由已识别且原执行路径已接受的连携增加一层，初始未跟踪层数不补满。pending不虚构15秒期限；战技按前捕获层数，接受才消费全部，失败/超时不消费。同一份捕获报价可用于当前技能的投射物名义分量，后续技能默认不复用；不声称已执行服务器OnBeforeCastSkill或完整SkillAffix的引用计数/回收。

J.E.T.的连携+33.6%/15秒与既有战技窗口独立；同类型重放只刷新、不叠额外份数。动态加成与固定增伤同桶相加，不把碾骨30%当最终伤害乘1.3。具名E失败、匿名E或未知变体不会生产这些效果。

完整回收/齐射报价采用所属原生profile的完整名义区间作保守窗口覆盖判定，只有交接点仍有效不够；本批不估算窗口仅覆盖部分伤害时的精确收益。旧连携J.E.T.中途到期时不整段给满，本次新战技J.E.T.可以独立覆盖；碾骨为当前cast快照，不按动画交接清理。
