# 连携技检测实测入口

在调试模式的「工具与调试」分组运行「连携技检测」。任务持续读取游戏画面，点击停止结束；不进入自动战斗、不按E、不切换角色、不释放任何技能。

任务复用正式 `BattleMixin.observe_link_skills` 和默认连携提示小框。提示出现后，最多识别四个固定头像槽，显示角色、编队槽位、匹配分数、次佳差和匹配范围；绿色框为识别成功，红色框为未知。未知槽不压缩位置、不阻断后项，不把历史顺序当成当帧队列。第四槽仍沿用已批准的71px公差外推，等待四槽实拍验证。

编队每两秒或画面尺寸变化时重识别，复用管理员性别线索，不逐帧扫描全角色。默认每轮检测后等待0.1秒；此等待与截图、检测和绘制开销相加，不能当作固定10Hz。界面和日志分列提示匹配、连携头像匹配、编队匹配的耗时，不包含截图、绘制或等待；本轮未重新识别编队时其耗时为0。首次资源加载及后续同像素缓存的差异会反映在头像耗时中。

请在游戏里手动触发连携、按E、等待提示消失或调整队伍，然后对照信息栏和框。提示消失会覆盖旧槽位信息；没有画面时显示未知并清除旧缓存，不宣称连携不存在。每次启动/停止都会清理本任务的队列和顺序记忆。

头像仅提供身份与显示顺序，不证明可施放、技能变体、剩余秒数、命中或释放成功。本任务不更改正式连携执行、时间保护、伤害报价、资源或增益状态。
