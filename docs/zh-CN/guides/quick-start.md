# 快速上手

## 启动任务

1. 按照[使用前配置](../getting-started/configuration.md)检查游戏窗口、画面和按键设置。
2. 启动 `ok-ef`，进入与任务相符的游戏场景。
3. 在应用中选择任务，并检查任务的配置项与前置条件。
4. 点击开始，任务运行期间观察日志和游戏画面。

日常任务、刷体力、自动战斗等功能的配置与限制见[功能概览](../features/overview.md)。

## 停止与恢复

画面与预期不一致、游戏窗口失焦或需要临时接管时，应立即在应用中停止任务。恢复前重新确认场景、窗口和前置条件，不要依赖长时间重复输入纠正异常画面。

## 定时执行

日常任务、自动送货、影拓丰碑及游戏启动检查任务支持内置计划任务。也可以通过 [Windows 计划任务](../../zh-CN/Windows%20计划任务.md) 调用已注册的一次性任务。
