# 使用前配置

运行自动化前，请完成以下检查。这些设置会直接影响识别和输入的稳定性。

## 游戏画面

- 使用 16:9 分辨率，要求 1920×1080（1080P）及以上；低于 1080P 不保证正常运行。
- 使用游戏默认亮度；关闭 NVIDIA Freestyle、AMD 图像滤镜、锐化和画面覆盖层。
- 运行时不要最小化游戏窗口，也不要锁屏或让屏幕熄灭。
- 战斗和导航任务建议保持稳定 60 FPS。

## 输入与窗口

- 若修改过游戏按键，请在应用设置中同步支持的按键配置。
- 游戏窗口和自动化程序的权限应一致；建议均以管理员权限启动。
- 前台运行任务期间避免移动鼠标或手动点击游戏窗口。
- 多账户任务需先在游戏中登录过待执行账号。

## 首次运行

1. 启动游戏并进入与目标任务相符的场景。
2. 启动 `ok-ef`，在任务列表中选择要运行的任务。
3. 阅读该任务的前置条件和配置说明，再点击开始。

相关任务细节见[功能概览](../features/overview.md)和[快速上手](../guides/quick-start.md)。
