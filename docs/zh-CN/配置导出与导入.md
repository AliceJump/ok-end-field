# 配置导出与导入

返回：[文档索引](index.md) / [README](https://github.com/AliceJump/ok-end-field/blob/master/README.md)

用于备份、恢复或在多台设备之间迁移应用配置。配置保存在应用目录的 `configs` 文件夹中，包括任务开关与参数、账号配置与账号任务覆盖、共享战斗配置、窗口与设备选择等。

## 1. 入口位置

打开应用的 Capture 页，在 Debug 卡片的按钮行中可以找到两个按钮：

- 导出配置
- 导入配置

## 2. 导出配置

1. 点击“导出配置”。
2. 应用会把 `configs` 目录打包为一个 zip 文件，保存到系统的下载文件夹，文件名形如 `ok-ef-config-20260907_010515.zip`。
3. 导出完成后会提示“配置已导出”，并自动在资源管理器中定位该文件。

导出的 zip 不包含日志与截图；`configs/backup`、`configs/global_config_migration_backup` 两个备份目录也不会被打包。

## 3. 导入配置

支持两种方式，效果相同：

- 点击“导入配置”按钮，在文件对话框中选择 zip 文件（默认从下载文件夹开始浏览）。
- 直接把 zip 文件拖入应用主窗口的任意位置；一次拖入多个 zip 时只会导入第一个。

对 zip 内容的要求：压缩包中至少要有一个 `.json` 配置文件。以下三种打包形态都可以识别：

1. 由“导出配置”生成的 zip（条目在 `configs/` 目录下）。
2. 配置文件直接放在压缩包根部。
3. 配置文件放在压缩包中的单个目录里（导入时该目录会被剥离，条目直接落到 `configs`）。

导入流程：

1. 确认对话框中点击确认后，应用会暂停运行中的任务。
2. 现有配置先备份到 `configs/backup/import_backup_<时间戳>/`，然后 `configs` 目录被导入内容覆盖（上述两个备份目录会保留）。
3. 导入完成后会提示“导入完成”，并询问是否立即重启。

## 4. 生效与回滚

- 导入只修改磁盘上的配置文件，正在运行的程序仍使用内存中的旧配置；点击“立即重启”或之后手动重启应用后才会生效。
- 需要回滚时，从 `configs/backup/import_backup_<时间戳>/` 把备份文件复制回 `configs` 目录（先关闭应用），或用导入前导出的 zip 再执行一次导入。
- 建议在相同或相近版本的应用之间导出导入；版本差异较大时，个别配置项可能被重置为默认值。

## 5. 常见问题

1. 导入按钮提示“压缩包中未找到配置文件”：zip 里没有 `.json` 文件，或选中的不是配置压缩包。
2. 拖入 zip 后没有反应：确认拖入的是 `.zip` 文件；个别自带拖放处理的输入框（如代码编辑区）不会触发导入。
3. 导出按钮提示“导出失败”：检查 `configs` 目录是否被其他程序占用（例如已打开的配置文件），重试即可。
