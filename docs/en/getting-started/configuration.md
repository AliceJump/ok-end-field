# Before you start

Complete these checks before starting automation. They directly affect recognition and input reliability.

## Game graphics

- Use a 16:9 resolution; 1920×1080 (1080P) or above is required.
- Use the game's default brightness. Disable NVIDIA Freestyle, AMD image filters, sharpening, and overlays.
- Do not minimize the game, lock the computer, or turn off the display while a task is running.
- Keep a stable 60 FPS for combat and navigation tasks where possible.

## Input and window state

- If you changed game keybindings, synchronize the supported keybinding configuration in the application.
- Run the game and automation application at the same privilege level; administrator privileges are recommended.
- Do not move the mouse or manually click the game window while a foreground task is running.
- For multi-account tasks, log in to every account that will be used before running the task.

## First run

1. Start the game and enter the scene required by the target task.
2. Start `ok-ef` and choose the task in the task list.
3. Read the task prerequisites and configuration description, then select **Start**.

See [Feature overview](../features/overview.md) and [Quick start](../guides/quick-start.md) for more detail.
