# Quick start

1. Review [Before you start](../getting-started/configuration.md), including the game window, graphics, and keybindings.
2. Launch `ok-ef` and enter the game scene required by the task.
3. Select a task in the application, then review its configuration and prerequisites.
4. Select **Start** and watch both the log and game screen while it runs.

See [Feature overview](../features/overview.md) for the configuration and limitations of dailies, farming, auto combat, and other features.

## Stop and recover

Stop the task immediately if the screen differs from expectations, the game window loses focus, or manual control is required. Before restarting, confirm the scene, window state, and prerequisites instead of relying on repeated input to correct an unexpected screen.

## Scheduled execution

Dailies, Auto Delivery, Monument, and game startup-check tasks support built-in scheduling. You can also use [Windows Task Scheduler](../../zh-CN/Windows%20计划任务.md) to run a registered one-time task on a schedule.
