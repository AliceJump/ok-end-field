  <section class="ef-section ef-section--faq">
    <div class="ef-section__heading"><h2>常见问题</h2></div>
    <div class="ef-faq-content">
      <h3>识别或点击不稳定</h3>
      <p>依次检查：</p>
      <ol><li>分辨率是否为 16:9 且不低于 1920×1080（1080P）。</li><li>游戏亮度、按键和画面设置是否符合任务要求。</li><li>是否关闭显卡滤镜、锐化和画面悬浮层。</li><li>游戏窗口是否没有最小化，屏幕是否没有锁定或熄灭。</li><li>运行时鼠标是否干扰了前台游戏窗口。</li></ol>
      <h3>安装或启动失败</h3>
      <ul><li>确认使用最新版安装包，并将安装目录加入安全软件信任列表。</li><li>源码运行时重新执行 <code>uv sync</code> 安装项目依赖。</li><li>避免在包含中文字符或异常权限限制的目录运行。</li></ul>
      <h3>反馈问题</h3>
      <p>在 <a href="https://github.com/AliceJump/ok-end-field/issues">GitHub Issues</a> 提交问题时，请附上清晰截图或录屏、已脱敏日志、复现步骤、实际结果和软件版本。不要上传账号信息、个人路径或密钥。</p>
